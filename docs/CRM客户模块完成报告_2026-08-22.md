# CRM 客户模块完成报告（2026-08-22）

## 1. 交付结论

CUS-02 至 CUS-08 已连续完成并通过真实 Django Session + CSRF 联调。客户列表、快捷新建、资料编辑、360 概览、客户内联系人、时间线与沟通、客户转移、重复客户治理形成完整闭环。

本次没有开发独立联系人模块，没有创建虚假订单、报价、询价、样品页面或假接口；人工及延时业务数据均明确展示数据来源、统计截止时间和录入人。现有数据和其他任务的未提交改动均被保留，未执行清理、重置或覆盖。

项目没有单独的登录页 Figma 原型；本模块也未取得新增 Figma 原型，因此按已确认的现有页面、交接报告和真实接口能力作为视觉与交互基线。

## 3. 原有实现的问题

1. 客户列表的新建与多个操作仍为提示信息，无法形成真实业务闭环。
2. 客户详情缺少统一的 360、编辑、联系人、时间线和转移工作区。
3. 前端没有覆盖客户实体、地址、历史属性、转移和重复治理的完整接口客户端。
4. 人工业务快照虽有后端基础，但前端没有清楚标注来源、截止时间和录入人，存在被误认为实时数据的风险。
5. 重复客户治理前端缺少候选决策、影响预览与事务合并流程。
6. 原演示数据不足以验证联系人、地址、时间线、转移和重复组的完整页面状态。

## 4. 本次修改

### 前端

- 新增快捷新建客户抽屉，支持防抖实时查重、选择已有客户、继续创建、状态与错误反馈。
- 新增统一客户详情工作区，按路由切换概览、资料、联系人、时间线、转移。
- 新增客户资料编辑，使用 ETag/`If-Match` 保存基础资料，并分别保存实体、地址、等级、来源和分类历史。
- 新增真实业务概览，人工或延时数据均展示来源和统计截止信息。
- 将现有联系人能力嵌入客户详情页签，没有扩展独立联系人模块。
- 新增真实沟通记录及可选后续任务创建。
- 新增转移申请和影响预览。
- 新增重复客户中心，支持字段对比、主客户选择、冲突决策、影响预览、忽略与合并。
- 完成桌面端和窄屏响应式适配。

### 后端

- 复用现有客户、联系人、沟通、任务、转移和重复治理接口；本轮未新增数据表。
- 增加幂等的客户模块演示数据命令，用于补齐实体、地址、联系人、沟通、任务、人工快照和重复案件的真实联调样本。
- 合并仍由后端事务服务执行并记录合并操作、成员及字段变更历史。

### 数据库

- 未创建新迁移；`makemigrations --check --dry-run` 返回 `No changes detected`。
- 运行幂等演示数据命令补充联调样本；重复运行不会清空或重建既有数据。
- 浏览器闭环产生的客户、沟通、任务和转移测试记录按要求保留，没有清理。

## 5. 最终业务流程

### 新建与维护

```text
打开客户列表
→ 打开快捷新建
→ 加载字典选项
→ 输入名称并实时查重
→ 选择已有客户，或确认继续创建
→ Django 权限与员工状态校验
→ 写入客户并跳转详情
→ 使用 ETag 编辑客户、实体、地址和历史属性
```

### 360 与互动

```text
打开客户详情
→ 并行获取客户详情、摘要、业务快照和关联信息
→ 明确展示实时/人工/延时数据边界
→ 懒加载时间线
→ 保存真实沟通记录
→ 可选创建后续任务
```

### 转移与重复治理

```text
查看影响预览
→ 提交客户转移申请
→ 后端执行权限、员工、任务策略和并发校验
→ 审批后保留归属历史并更新权限

打开重复组
→ 对比真实字段
→ 选择主客户并完成候选决策
→ 获取后端影响预览
→ 带 If-Match 提交合并
→ 后端事务迁移关联并保留完整历史
```

## 6. 异常处理

| 场景 | 处理方式 |
| --- | --- |
| 400 | 显示后端字段或业务校验信息，保留用户输入 |
| 401 | 由统一会话处理回到登录，不保存密码或令牌 |
| 403 | 显示权限不足，不提供假成功状态 |
| 409 | 显示业务冲突，例如重复候选尚未完成决策 |
| 412 | 提示数据已被他人修改，要求刷新后重试 |
| 428 | 提示缺少版本条件，阻止无版本写入 |
| 500 | 显示服务异常，保留当前输入并允许重试 |
| 网络异常 | 显示网络连接失败，Loading 正常结束，不误报成功 |
| 未上线模块 | 禁用或提示尚未完成，不创建假页面或假 API |

所有写操作继续使用 Django Session + CSRF；未引入 JWT、LocalStorage Token 或 Refresh Token。

## 8. 当前限制与风险

1. 项目没有 `lint` 脚本，本次未擅自引入 ESLint；以类型检查、单元测试和生产构建作为前端静态门禁。
2. 生产构建存在包体超过 500 kB 的性能警告，当前不阻塞功能交付；后续可按路由拆包，但不应在本次范围内做全局重构。
3. `@vueuse/core` 的纯函数注释位置产生 Rollup 警告，构建工具已安全移除该注释，产物生成成功。
4. 订单、报价、询价、样品等模块若没有真实详情路由，客户概览只显示真实汇总或禁用入口。
5. 人工业务快照允许延时，用户判断经营状态时必须关注页面显示的来源和统计截止时间。
6. 客户转移的真实审批需要对应审批角色在业务环境中完成；自动化测试已覆盖审批后的归属历史。
