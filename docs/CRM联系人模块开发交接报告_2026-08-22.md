## 5. 导入与病毒扫描配置

新增环境变量：

```text
CLAMAV_HOST=clamav
CLAMAV_PORT=3310
CLAMAV_TIMEOUT=15
CONTACT_IMPORT_MAX_BYTES=5242880
CONTACT_IMPORT_MAX_ROWS=500
```

Docker Compose 使用 `clamav/clamav:1.5.4`，3310 端口只存在于 Compose 内网，不映射宿主机。后端通过标准库 socket 使用 `INSTREAM` 协议扫描，仅新增 XLSX 解析依赖 `openpyxl`。

同步导入限制为 5MB、500 行；CSV 支持 UTF-8/UTF-8-SIG，XLSX 只读取第一张工作表并拒绝公式、宏、外部链接及异常压缩包。
