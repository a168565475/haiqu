# PROD-00 / PROD-01 生产任务单模块开发完成报告

## 完成范围

- Figma 主文件新增 `[草案] PROD-00 生产任务单列表 / 1920`，仅按 1920 桌面端验收。
- 左侧导航新增“生产计划”，进入生产任务单列表。
- 新增生产任务单列表、详情、新增、编辑路由。
- 新增生产任务单后端业务模块、数据库表、编号规则、列表/详情/新增/修改/选项/统计/提交校验接口。
- 基础信息支持：自动合同编号、订单来源、订单号、客户、下单日期、交期、业务员、多人跟单、币种、含税、订单误差、翻单、产前确认样、交货方式、订单特殊要求富文本。
- 新建页默认维护一个产品，可为该产品添加多条颜色和数量明细；页面不显示添加产品或删除产品操作。
- 产品信息底部提供费用与汇总区块，保存运费和其他费用，并实时只读计算产品合计数量与订单合计金额。
- 合同编号由系统预生成默认值，但允许在新建或编辑时修改；保存时校验编号格式和唯一性。
- 基础信息币种使用系统设置数据，并支持按币种代码或名称搜索。
- 整单保留订单特殊要求富文本；包装方式和产品特殊要求随产品绑定，在“生产任务单明细”弹窗中填写。
- 产品信息从产品档案选择；每条颜色明细支持多张图片、色卡三级联动、整数订单数量、售价、合计金额、3 位小数汇率和本币金额计算。
- 每个产品拥有一份生产任务单明细，复用新增样品“打样信息明细”的类型、类别项、是否、描述和图片结构，不再使用独立选项卡。
- 分批数量存在时，提交校验会比较任务总数和分批合计；有差异时明确拦截，不自动修改数量。

## 路由与接口

- 前端列表：`/production-tasks`
- 前端新增：`/production-tasks/new`
- 前端详情：`/production-tasks/:taskId`
- 前端编辑：`/production-tasks/:taskId/edit`
- API：`/api/v1/production-tasks/`
- API 选项：`/api/v1/production-tasks/options/`
- API 统计：`/api/v1/production-tasks/stats/`
- API 提交校验：`/api/v1/production-tasks/:taskId/submit/`
