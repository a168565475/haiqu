# SAM-09 样品库第一页面开发说明

## 本轮范围

- 只开发 1920 桌面端“样品库 / 样品库存”列表页。
- 左侧样品管理菜单删除“样品入库、样品出库、样品借出、样品库存”，合并为“样品库”。
- 入库、出库、借出弹窗和详情页不在本轮实现，页面按钮只提示后续开发，不提交数据。
- 不复用“样品寄送”作为库存出库，避免混淆客户物流与仓库扣减。

## 数据模型

- `SampleInventoryReceipt`：入库单头，保存入库编号、提交人、提交时间。
- `SampleInventoryLine`：入库明细，保存来源样品明细、产品快照、打样数量、入库数量、累计出库数量、借出数量和入库位置。
- 可用库存计算：`入库数量 - 累计出库数量 - 借出数量`。
- 列表只返回可用库存大于 0 的明细。

## 接口

- `GET /api/v1/sample-inventory/`：库存分页列表；支持关键词、产品类别、入库位置筛选。
- `GET /api/v1/sample-inventory/summary/`：当前可用库存、借出中、今日入库统计。
- `GET /api/v1/sample-inventory/options/`：产品类别和入库位置筛选选项。
- 权限：`samples.view_sampleinventoryline`。

## 明确未完成

- 出库流水尚未建模，因此“今日出库”返回空值，前端显示“—”，不能用固定数字冒充真实统计。
- 入库、出库、借出的写接口、编号生成、并发扣减、操作权限和详情页将在对应页面确认后分单元开发。
- 本轮只创建前向 Migration，不执行开发数据库迁移；执行迁移必须另行确认。
