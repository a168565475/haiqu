# SAM-09 样品库第三页面开发说明

## 本轮范围

- 已开发“样品库 / 样品借出”列表页，仅按 1920×1080 桌面端验收。
- 列表按借出单明细行展示；同一借出单包含多条样品时，借出编号允许重复。
- 本轮只提供历史记录的真实只读接口，不包含借出弹窗、提交、自动编号、库存占用写入、导出和借出单详情页。
- 按已确认业务规则，本轮不增加预计归还日、归还按钮或归还状态。

## 页面字段

表格按 Figma 顺序展示：借出编号、操作人、操作时间、样品跟进单号、产品类别、产品名称、规格 / 颜色、借出数、借用人、用途 / 备注、操作。

筛选项包括：关键词、借用人、产品类别、操作时间。列表、筛选选项和统计值均来自接口，不使用前端 Mock 充当业务功能。

## 统计口径

- 借出中：当前借出单数量。由于本轮没有归还状态，所有借出单都视为借出中。
- 累计借出：借出数量合计。
- 客户现场确认：用途 / 备注中包含“客户”或“确认”的借出数量合计。
- 展厅 / 拍摄：用途 / 备注中包含“展厅”或“拍摄”的借出数量合计。

后两项是为了对应当前 Figma 指标卡而采用的关键词统计，不是稳定的结构化业务分类。若后续需要准确报表，应在借出弹窗和 PRD 中新增“用途类型”字段，不能长期依赖自由文本判断。

## 后端数据与接口

- `SampleInventoryLoan`：借出单头，保存借出编号、操作人和操作时间。
- `SampleInventoryLoanLine`：借出单明细，关联来源入库批次，保存借出数量、借用人和用途备注。
- `GET /api/v1/sample-loans/`：分页明细列表。
- `GET /api/v1/sample-loans/summary/`：借出统计。
- `GET /api/v1/sample-loans/options/`：借用人和产品类别选项。
- 权限：`samples.view_sampleinventoryloanline`。

模型已校验借出数量必须大于零，借用人和用途备注不能为空。

## 暂不执行的数据库操作

新增迁移为 `0017_sample_inventory_loan.py`，依赖 `0016_sample_inventory_outbound.py`。根据当前开发权限，本轮没有对开发数据库执行 `migrate`，也没有为角色分配新权限。进入联调环境前，应由项目负责人确认后执行 `0015` 至 `0017` 迁移，并按角色分配查看权限。

后续实现借出提交时，必须在同一数据库事务中创建借出单和明细，并同步增加来源库存行的借出数量；还需增加并发校验，避免多人同时操作导致可用库存变成负数。本轮只读列表不承担这部分写入规则。

## 验证结果

- Django 系统检查通过，模型与迁移一致。
- 库存、出库及借出后端定向测试共 15 项通过。
- OpenAPI 生成校验为 0 错误；现有项目仍有与本页无关的历史警告。
- 前端类型检查、三个样品库页面的定向测试、生产构建均通过。
- 1920×1080 浏览器截图使用接口拦截数据仅做视觉验收，不代表开发数据库已存在借出记录。
