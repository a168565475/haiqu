# SAM-09 样品库第二页面开发说明

## 本轮范围

- 已开发“样品库 / 样品出库”列表页，仅按 1920×1080 桌面端验收。
- 列表按出库单明细行展示；同一出库单包含多条样品时，出库编号允许重复。
- 本轮只提供历史记录的真实只读接口，不包含出库弹窗、提交、自动编号、库存扣减、导出和出库单详情页。
- “样品借出”仍为待开发页面，需在本页确认后继续。

## 页面字段

表格按 Figma 顺序展示：出库编号、操作人、操作时间、样品跟进单号、产品类别、产品名称、规格 / 颜色、出库数、出库方式、快递公司、快递单号 / 备注、操作。

筛选项包括：关键词、出库方式、产品类别、操作时间。统计项包括：今日出库、本月出库、跟单员邮寄、业务员带走，四项都按出库数量求和，不按单据数计数。所有列表、筛选选项和统计值均来自接口，不使用前端 Mock 充当业务功能。

## 后端数据与接口

- `SampleInventoryOutbound`：出库单头，保存出库编号、操作人和操作时间。
- `SampleInventoryOutboundLine`：出库单明细，关联来源入库批次，保存出库数量、出库方式、快递公司、快递单号和备注。
- `GET /api/v1/sample-outbound/`：分页明细列表。
- `GET /api/v1/sample-outbound/summary/`：出库统计。
- `GET /api/v1/sample-outbound/options/`：出库方式和产品类别选项。
- 权限：`samples.view_sampleinventoryoutboundline`。

模型已加入条件校验：跟单员邮寄必须同时填写快递公司和快递单号；其他方式必须填写备注；业务员带走不要求快递字段。

## 暂不执行的数据库操作

新增迁移为 `0016_sample_inventory_outbound.py`，并依赖第一页面的 `0015_sample_inventory.py`。根据当前开发权限，本轮没有对开发数据库执行 `migrate`，也没有为角色分配新权限。进入联调环境前，应由项目负责人确认后执行迁移并按角色分配查看权限。

后续实现出库提交时，必须在同一数据库事务中创建出库单和明细，并同步增加来源库存行的已出库数量；还需增加并发校验，避免多人同时出库导致可用库存变成负数。本轮只读列表不承担这部分写入规则。
