# SAM-10B 样品出库批量选择弹窗开发说明

## 本轮范围

- 只开发 1920 桌面端“样品出库”批量选择弹窗，不开发借出弹窗或详情页。
- 弹窗接入已确认的样品出库列表页，沿用当前样品库黑白视觉、表格和 Noto Sans SC 字体。
- Figma 示例只用于字段、尺寸和交互结构；正式候选库存与提交结果均来自真实接口。

## 出库规则

- 仅返回当前可用库存大于 0 的入库批次明细。
- 每条明细分别填写出库数量和出库方式；出库数量必须为正整数且不能超过可用库存。
- 跟单员邮寄：快递公司和快递单号必填，备注不保存。
- 业务员带走：快递公司、快递单号和备注均不保存。
- 其他：备注必填，快递公司和快递单号不保存。
- 提交时携带页面加载时的可用库存快照；后端事务内锁定入库批次并重新计算，库存变化时返回 409。

## 接口与权限

- `GET /api/v1/sample-outbound/eligible/`：返回当前可出库库存批次，单次最多 100 条。
- `POST /api/v1/sample-outbound/documents/`：在同一事务内生成出库单、出库明细并累计库存出库数量。
- 两个接口均要求 `samples.add_sampleinventoryoutbound` 权限；操作人必须绑定有效员工档案。
- 出库人和出库时间由后端从当前账号及系统时间写入，前端不允许伪造。

## 编号说明

- Figma 中的 `CK-日期-序号` 只是原型占位。
- 当前编号基础设施的兼容格式为 `CK-YYYYMM-六位序号`，由数据库序列保证唯一性。
- 新增迁移 `0019_sample_inventory_outbound_sequence.py` 创建出库编号序列。

## 验证结果

- 后端覆盖候选库存、正常扣减、超库存、库存快照失效、条件字段、重复明细和权限。
- 前端覆盖候选加载、未选择拦截、方式选择和真实提交参数。
- 1920 浏览器验收确认弹窗坐标 `x=210, y=160`，尺寸 `1500×760`，8 列顺序正确。
