# SAM-10C 样品借出批量选择弹窗开发说明

## 本轮范围

- 只开发 1920 桌面端“样品借出”批量选择弹窗，不开发入库单、出库单或借出单详情页。
- 弹窗接入已确认的样品借出列表页，沿用当前样品库黑白视觉、表格和 Noto Sans SC 字体。
- Figma 示例只用于字段、尺寸和交互结构；正式候选库存与提交结果均来自真实接口。

## 借出规则

- 仅返回当前可用库存大于 0 的入库批次明细。
- 每条明细分别填写借出数量、借用人和用途 / 备注，三个字段均必填。
- 借出数量必须为正整数且不能超过当前可用库存。
- 借出数量持续占用可用库存；本轮不包含预计归还日、归还按钮和归还状态。
- 提交时携带页面加载时的可用库存快照；后端事务内锁定入库批次并重新计算，库存变化时返回 409。

## 接口与权限

- `GET /api/v1/sample-loans/eligible/`：返回当前可借出库存批次，单次最多 100 条。
- `POST /api/v1/sample-loans/documents/`：在同一事务内生成借出单、借出明细并累计库存借出数量。
- 两个接口均要求 `samples.add_sampleinventoryloan` 权限；操作人必须绑定有效员工档案。
- 提交人和提交时间由后端从当前账号及系统时间写入，前端不允许伪造。

## 编号说明

- Figma 中的 `JC-日期-序号` 只是原型占位。
- 当前编号基础设施的兼容格式为 `JC-YYYYMM-六位序号`，由数据库序列保证唯一性。
- 新增迁移 `0020_sample_inventory_loan_sequence.py` 创建借出编号序列。

## 验证结果

- 后端覆盖候选库存、正常占用、超库存、库存快照失效、必填字段、重复明细和权限。
- 前端覆盖候选加载、未选择拦截、借出字段填写和真实提交参数。
- 1920 浏览器验收确认弹窗坐标 `x=210, y=160`，尺寸 `1500×760`，7 列顺序正确。
- 浏览器截图中的候选和借出数据仅用于视觉验收，不会写入业务数据库。
