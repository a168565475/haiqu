# SAM-11A 样品入库单详情页开发说明

## 本轮范围

- 只开发 1920 桌面端“样品入库单详情页”，不开发出库单或借出单详情页。
- 页面沿用当前 haiqu ERP 侧栏、顶部栏、白色卡片、黑色按钮及 Noto Sans SC 字体。
- 入库列表中的“样品入库编号”已改为进入对应真实单据详情，不使用前端 Mock 代替业务接口。

## 页面内容

- 单据概要：入库编号、单据类型、提交人、提交时间、操作来源和完成状态。
- 操作信息：分批 / 多次入库规则、累计入库数量上限。
- 入库明细：样品跟进单号、产品类别、产品名称、规格 / 颜色、打样数量、本次入库、累计入库、入库位置和流程条件。
- 来源样品跟进单：跟进单号、产品名称、流程状态和流程条件，可进入对应样品跟进详情。
- 页面为只读详情，不提供编辑或删除入口。

## 接口与权限

- `GET /api/v1/sample-inventory/receipts/{receipt_id}/`：按入库单标识返回单据头及全部入库明细。
- 接口要求 `samples.view_sampleinventoryline` 权限，并要求当前账号绑定有效员工档案。
- 不存在的单据返回 404；无权限返回 403；前端分别显示明确提示和重新加载入口。
- “累计入库”由后端按同一样品明细的所有入库批次实时汇总，不使用页面硬编码。

## 数据与迁移

- 本轮复用 `SampleInventoryReceipt`、`SampleInventoryLine`、`SampleItem` 和样品流程记录，没有新增数据库字段或迁移。
- 样品库基础迁移 `0015`～`0020` 在当前开发数据库中仍未执行，本轮没有擅自修改数据库。

## 验证结果

- 后端覆盖详情单据头、明细、跨批次累计入库、流程条件、来源状态、404 和权限。
- 前端覆盖详情加载、9 列顺序、来源信息、返回列表和库存列表编号跳转。
- 1920 浏览器验收确认五个区块均为 1632 像素宽，高度依次为 148、108、300、200、64 像素。
- 浏览器截图数据只用于视觉验收，不写入业务数据库。
