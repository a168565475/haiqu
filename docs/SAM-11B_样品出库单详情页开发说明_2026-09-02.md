# SAM-11B 样品出库单详情页开发说明

## 本轮范围

- 只开发 1920 桌面端“样品出库单详情页”，不开发借出单详情页。
- 页面沿用当前 haiqu ERP 侧栏、顶部栏、白色卡片、黑色按钮及 Noto Sans SC 字体。
- 出库列表中的“出库编号”和“查看”已进入对应真实单据详情，不使用前端 Mock 代替业务接口。

## 页面内容

- 单据概要：出库编号、单据类型、提交人、提交时间、操作来源和完成状态。
- 操作信息：出库方式按明细保存，操作数量不得超过提交时可用库存。
- 出库明细：来源入库批次、样品跟进单号、产品名称、规格 / 颜色、出库数量、出库方式、快递公司、快递单号和备注。
- 邮寄明细显示快递公司和快递单号；业务员带走等非邮寄明细的快递字段显示“—”。
- 来源入库批次可进入入库单详情；来源样品跟进单可进入对应样品跟进详情。
- 页面为只读详情，不提供编辑或删除入口。

## 接口与权限

- `GET /api/v1/sample-outbound/documents/{outbound_id}/`：按出库单标识返回单据头及全部出库明细。
- 接口要求 `samples.view_sampleinventoryoutboundline` 权限，并要求当前账号绑定有效员工档案。
- 不存在的单据返回 404；无权限返回 403；前端分别显示明确提示和重新加载入口。
- 出库方式、快递信息和备注均读取每条真实出库明细，不使用页面硬编码。

## 数据与迁移

- 本轮复用 `SampleInventoryOutbound`、`SampleInventoryOutboundLine`、`SampleInventoryLine` 和样品明细，没有新增数据库字段或迁移。
- 样品库基础迁移 `0015`～`0020` 在当前开发数据库中仍未执行，本轮没有擅自修改数据库。

## 验证结果

- 后端覆盖单据头、多条明细、邮寄与带走字段差异、404 和权限。
- 前端覆盖详情加载、9 列顺序、快递字段空值、来源信息、返回列表和出库列表编号跳转。
- 1920 浏览器验收确认五个区块均为 1632 像素宽，高度依次为 148、108、300、200、64 像素。
- 表头与明细行使用相同列宽，并验证横向起点和总宽一致。
- 浏览器截图数据只用于视觉验收，不写入业务数据库。
