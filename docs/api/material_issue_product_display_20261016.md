# 生产领料产品展示接口补充

日期：2026-10-16。范围仅产品图片和展示属性；领料需求、申请数量、库存扣减、审核、并发版本规则不变。

## 产品展示字段

`GET /api/v1/material-issues/eligible-products/?production_task_id={task_id}` 的每个产品，以及领料列表/详情响应的 `product` 增加：

| 字段 | 含义 |
| --- | --- |
| `specification_display` | 产品纯规格；仅剥离任务独立颜色、材质字段能够证实的旧拼接尾缀 |
| `material` | 生产任务产品材质快照，缺失时为空 |

原 `specification` 保留原始快照；`color` 保持原义。列表把纯规格、颜色和材质各列显示，空值显示“—”。

`image_file_id` 优先使用任务产品的可用主图，其次使用多图；没有可用任务图时，读取该产品明确关联的销售订单产品图，要求来源属于任务的同一销售订单和交付批次。不会按相同产品编号借用其他订单图片，也不改写历史任务或领料数据。

## 图片读取

`GET /api/v1/material-issues/product-images/{task_id}/{file_id}/`

- 沿用 Session 登录、有效员工检查。
- 要求 `material_issues.view_materialissue`，不要求排产查看权限。优先按生产任务可见范围校验；只能查看领料单而无整张任务权限的用户，仅可读取其可见领料单明确关联的产品图，不放开同任务其他产品图片。
- 文件必须是该任务已关联图片或上述明确关联的订单产品图。
- 保留归档、现有文件扫描策略、文件存储路径边界与文件存在检查。
- 无业务权限返回 403；任务/图片不在可读范围或文件不存在返回 404；文件未通过现有安全扫描策略返回 400。

新增、编辑和详情页面均使用此领料图片入口。读取操作不创建领料单、不预占或扣减库存。
