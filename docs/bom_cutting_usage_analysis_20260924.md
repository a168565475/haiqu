# 裁剪明细“单个用量”只读核对（2026-09-24）

用户本轮明确：单个用量指每一片裁片耗用多少米布，例如0.5米／片；例如2片组成1套。本轮仅分析，不授权修改BOM、采购、库存或业务代码。生产继续事项仍保留，成品入库与交货仍不办理；喷塑回货数量尚未确认。

## 当前实现事实

1. `BomEditorView.vue` 的裁剪表格和行编辑弹窗没有独立的“单个用量”输入；弹窗有“裁片量”“来源面料”“每套耗米”。每套耗米目前手填，不由裁片量自动计算。
2. `processing_required_quantity` 优先取 `cut_piece_quantity`，为空才取 `unit_consumption`，然后乘订单量。二者不是乘数关系。
3. 标准外发裁片的产出单位固定为套，预计套数为发出米数除以每套耗米后向下取整；没有独立的“每套几片”换算字段。
4. 面料采购取面料行的单个用量乘订单量，不自动由所有关联裁片的耗米汇总反算。
5. 当前BOM0000399订单105张，面料单个用量1.75米，合计183.75米。四条裁剪行单位均为套，单个用量字段均为空。椅面裁片量2／每套耗米0.125，左扶手3／0.125，右扶手1／0.125，床面1／1。
6. 只读纯函数验证：裁片量2、订单100时，将单个用量分别设为0.5、1、3，结果都为200；只有裁片量为空时才使用单个用量。验证没有保存任何记录。

## 用户新明确含义下的正确计算

每套耗米＝每套裁片数×每片耗米。

例如每套2片、每片0.5米，则每套需要1米。若订单100个成品、每个成品需要1套该部位，则需要100套、200片、100米，不能把200片当成200套。

不同部位分别核算后，同一来源面料按米汇总。若各片耗米不同，应分别记录后求和，不能套用相同单片耗米。

当前缺口不仅是少一个输入框：还须明确裁片量为片／套、单个用量为米／片、每套耗米为米／套，以及每成品需要几套；需求数量、外发预计套数及面料需求须采用一致口径。是否自动回写面料采购建议属于后续改动方案，不能在本轮直接操作。

现有183.75米按此前模拟中“裁片量作为每成品套数”的口径复算可以对上，但不能据此证明每套片数的真实含义已经正确表达。现有0.125和1.0均保存为每套耗米，不能未经核实直接改名当作每片耗米，避免再次乘片数造成重复计算。

## 结论

按用户确认的“单个用量＝米／片”，当前裁剪明细缺少该独立输入和自动乘算，且裁片量被用于套数需求，存在片与套的语义缺口。应先形成具体字段、公式及历史数据处理方案，再按用户确认范围修改。本轮没有进行业务写入。
