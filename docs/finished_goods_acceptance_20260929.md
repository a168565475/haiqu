- 前端类型检查和构建通过；构建保留已有大资源包提示，本轮未扩大范围拆包。
- 迁移一致性检查 `makemigrations --check --dry-run`：No changes detected。新增0019仅创建装配来源表；测试库/验收库已应用，主库未应用。

## 依赖、边界和下一步

沿用项目Vue、Django、PostgreSQL及现有组件，没有新增业务依赖。包装仍按已确认规则选填：不填写时箱位显示“未计算”，不能据此当作已知的容量占用；材料与产出差异仍人工核对。
