# 裁片丝印外发

跟单在本人跟进的生产任务中选出要丝印的裁片。选中一种裁片就按订单和 BOM 的整项需求安排。仓库分批发出、分批收回，收回后仍是该裁片，并显示「已丝印」。

吴杰可以提前建立车缝外发单。仓库从仓内给车缝厂发已丝印裁片时，按本任务该裁片的实际回仓可用数量发出。从丝印厂直接交给车缝厂时，仓库选择「加工点发出」，关联原丝印单和实际交出的裁片。直送只登记一次交接，不产生回仓或仓库出库记录。普通裁片沿用原来源。

## 核对场景

- 跟单只办理本人跟进任务的裁片丝印单，仓库凭原有发出和收回权限操作，核对两个入口都不能借此办理其他工艺。
- 订单 100 件、每件该裁片 2 片，计划固定为 200 片。发出 50 片，先回 30 片，两次领用之间按实扣减；即使同规格未印裁片有库存，也不能补足已印裁片的可发数。
- 核对无回货时仍可建车缝单、普通裁片照常发出，旧部位丝印和厂内流程沿用原业务规则。
- 发给丝印厂 100 片、直送车缝厂 50 片、回仓 30 片后，丝印厂只能再交 20 片。直送重复提交只计一次，更正和作废恢复原丝印单额度；生产任务计入该批已交付裁片的丝印费一次。
