# 委外加工入口与排产前丝印

跟单可以用本人跟进任务的已确认 BOM 建丝印单，整项裁片按订单需求安排。仓库在实际发出时核对已裁数量或裁片库存。已有排产、未排产的任务共用一个入口。新单有生产任务产品归属，原排产和原收发记录继续按原单追溯。

车间的委外加工页集中提供管材、车缝、丝印三个建单按钮，按岗位授权显示。车缝建单固定使用车缝工艺，辅料在仓库实际发料时选填。车间移除“待外发材料”页签，生产领料和金工计划仍可按原任务登记金工完成。
