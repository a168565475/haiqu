## 2. 页面设计清单

1. 厂内半成品入库表单：自动带入计划、订单、产品、工序；部位逐行显示材质/规格等适用属性、单位、BOM单耗、订单数量、应入库、累计已入、剩余、本次数量；填写位置、日期、备注。需喷塑件不进入可厂内入库清单，并提供明确路径说明。不增加待审入库占用。
2. 半成品入库记录及详情：全部/厂内/外发筛选，订单、产品、部位、来源、阶段、时间、数量、单位、位置、操作人、状态及原单链接。公共余额可合并，但每次入库记录独立保存。
3. 现有页面局部调整：计划操作和进度、库存页签与记录入口；成品弹窗优先复用，不重新设计一套。若实际无法承载再补对应设计。

新页面必须先交图稿确认后开发。用户已选择仓管直接确认，可按“取消／确认入库”及“已入库”记录状态出图，不增加审核界面。

## 3. 入库操作规则已确认

用户已选择A：仓管填写实收数量后直接确认入库。原选项保留用于追溯：

- A（推荐）：点击“确认入库”立即生效，不新增审核。
- B：先提交，由另一名有权限人员审核入库。

影响：A无需待审占用与审核页面，但仍需确认时事务校验和防重复；B需要提交/待审/审核结果、额度占用及独立审核权限。此前只确定仓库操作，未确定是否复核，故该问题不是重复索取开发许可。

成品仍保留已选B的订单偏差上限；此处A/B是半成品审核方式，不能与成品上限选择混淆。

## 4. 权限与代码依据

- `src/frontend/src/views/workshop/WorkshopPlanListView.vue`：共享计划页、工价/报工独立权限以及金工登记入口。

- `src/backend/apps/production_scheduling/api/views.py`：计划列表读取要求`production_scheduling.view_productionschedule`。

仓管需要计划查看与对应入库权限，不自动获得排产编辑、工价或工资权限。本步未查询或修改任何员工真实授权，普通仓管可见范围需实现时验证。
