## 3. 建议业务流程

### 车缝

面料仓按米出库 → 厂内裁剪及车间内流转 → 车缝实物交仓 → 仓管登记并确认半成品入库 → 后续工序领取。不要求车间先提交入库申请。

- 用户已明确裁剪不入库，直接交给车缝；裁剪交接不增加库存，不生成一次虚拟入库再出库。
- 车缝按BOM部件分别计算应入库数量、累计入库、待入库及完成状态，遵循与金工相同的封顶规则。按既有套口径计量的部件，数量上限＝每件成品所需套数×订单数量，不能把耗布米数当成套数。
- 座布、靠背布等各部件分别管理，全部本工序应完成部件达到各自入库需求，才判定车缝完成；不自行把多个部件合并为一份完整布面套。若实际BOM表达的是组合件，需明确组成后映射，不能只按同面料、同颜色合并。
- 米数在原料领用时扣一次，车缝完工和入库不再扣面料。入库增加半成品套数；后续领取只扣半成品套数。

### 金工（路线已确认）

不需要继续外发喷塑、厂内已完成所需工艺的部件：原料领出 → 金工加工完成 → 仓管在金工计划办理半成品入库 → 装配按需领取。

需要喷塑的部件：原料领出 → 厂内金工加工 → 沿用现有外发喷塑交接、发出和回货流程 → 喷塑回货入半成品仓 → 装配按需领取。

- 需要喷塑的部件不经过新增厂内半成品入库；保留现有金工加工登记及外发交接，不新增未喷塑库存和从该库存外发的操作。
- 喷塑回货在统一半成品明细中标记“外发入库”，保留外发单、加工厂及回货记录；不得再通过金工计划补一张厂内入库造成重复库存。
- 金工计划的厂内入库清单须依据已有工艺路线区分部件，不能让仓管任意把待喷塑件作为可装配件入库。订单同时包含两类部件时分别显示其路径、加工/交接及入库进度。
- 需喷塑部件沿用既有加工及交接进度；新增厂内入库完成规则只适用于实际走厂内入库的部件，不能因没有未喷塑入库而让既有外发路线永远不能完成。混合路线的工序汇总应在开发前核对现有状态计算，不把喷塑回货自动当成新增一次厂内加工完成。
- 外发单原有发出、回货数量核对继续有效，不重写喷塑收发流程；原料直接外发路径也保留。新增来源展示及统一防重复校验不等于新增一套喷塑业务。

### 装配（新增方案范围）

按需领取公共半成品及适用辅料 → 装配实物完成 → 仓管在内部作业计划的装配产品行办理“成品入库” → 增加成品仓库存并更新装配入库进度。

- 支持分次入库，沿用生产订单产品单位，例如把、张、件；不得使用管材支数或车缝套数作为整件成品数量。
- 复用现有成品入库单据和库存服务，增加装配计划关联；不建立另一套成品余额。仓库现有成品入库入口若保留，也必须共用累计额度、进度更新和防重复规则；不能换入口再次入同一份产出。
- 成品入库只增加成品库存，前面领料已扣除的半成品和原料不再扣一遍；实际领用投入与产出数量的校验口径在开发前明确，不由报工次数自动产生库存。
- 建议累计有效成品入库达到订单产品净需求时，该产品装配进度显示完成；偏差额度是允许的上限，不作为必须生产的目标。库存被后续发货扣减不重新开放入库额度；进度完成不自动关闭尚合法的偏差内入库，也不自动改变生产订单状态。此完成口径属于建议，开发前定稿。装配完成不自动代表销售交付或整个订单已结清。
- 用户已选择B：保留现有成品上限＝floor(订单产品数量×(1＋订单允许偏差比例))；本次剩余可入＝max(0, 上限－累计有效成品入库－其他有效入库占用)。例：1000把且该订单偏差为2%，上限1020把；2%只是例子，不改写订单设置。金工/车缝半成品仍按BOM净需求封顶，不能套用成品偏差。修改订单数量或偏差比例后需重新核对既有入库，具体变更门禁沿用或核查现有规则，不自动删账。

## 4. 完工、入库和领用的数量控制

| 动作 | 建议控制 | 库存变化 |
| --- | --- | --- |
| 原料领用 | 延续订单已确认原料额度，累计厂内领用与原料外发不能各领一份 | 扣原料 |
| 仓管登记入库 | 由计划行带入订单、产品、工序，BOM带出部件；部件剩余额度＝max(0, BOM单个用量×订单数量－累计有效入库)。按实收数量填写，无待审入库占用 | 未确认前不增加可用库存 |
| 仓库确认入库 | 再次校验部件剩余额度、合法工艺阶段及投入产出约束；相同投入不得重复支撑产出。既有完工登记的衔接另定，不将其擅自作为新增强制前置操作 | 增加对应阶段半成品，并更新部件入库进度 |
| 装配领料 | 时间、部件和本次数量由车间决定，可分次、可只选部分部件；不能超过订单剩余需求或公共库存扣除有效占用后的可用量；不以金工/车缝全部完成或全部部件配齐作为提交条件 | 扣半成品，不扣原料 |
| 外发回货 | 同阶段已发、已回独立累计，不能重复回货 | 增加下一阶段半成品 |
| 装配成品入库 | 按生产订单产品跨单据、跨入口累计；上限沿用订单数量加订单允许偏差比例，向下取整，分次不能绕过 | 只增加成品库存，同步装配入库进度 |

仓库收货支持分次，已明确仓管直接确认入库，不新增审核及待审核入库占用。未确认的填写内容不增加库存或完成量。确认请求应可安全重复提交，同一请求只产生一次库存变化；并发确认需锁定相关额度和余额。

**本段按用户最新规则替换此前“额外合格件可直接入公共仓”的建议。** 厂内该部件累计有效入库不得超过BOM净需求，不把采购1%余量、管材整根取整或多领的原料换算数量加进入库上限。即使投入最多能加工4004支，而BOM需求为4000支，该订单部件仍只能入库4000支；不能借分次、换入库单、换库区绕过。剩余原料或已加工余件的具体处理另定，不自动补入库存，也不新增报废规则。

该上限针对本次新增厂内加工入库，不能未经确认反向改写此前外发已入库数量或历史库存。同一部件如同时存在厂内和委外供给，需按工序统一定义额度，防止两条路径各入一整份。需要喷塑的部件走现有外发路径，不额外产生一次厂内未喷塑入库；既有加工量与实际回货入库量也不能相加作为入库总量。

统一控制建议：对同一订单产品、同一BOM部位、同一目标加工阶段，厂内和外发产出共同占用该阶段净需求额度；外发回货还需满足对应外发单的剩余可回货量，取两者中较小者。此项用于新流程设计，旧外发单、超净需求的历史合法记录以及公共半成品转由其他订单加工时如何承接，须在上线前给出明确映射和处理方案，不能静默改写原规则。来源订单的额度与公共库存余额分开，不能通过改来源或改部位绕过封顶。

### 4.1 部件、工序与库存分开记进度

| 维度 | 规则 |
| --- | --- |
| 部件应入库 | 当前订单产品的BOM单个用量×订单数量；正整数支/套，来源BOM或单位不完整时阻止，不默认为0 |
| 部件已完成 | 仓库已确认的累计有效入库数量等于该部件应入库数量；未确认内容不计完成 |
| 部件未完成 | 累计有效入库小于需求；展示剩余数量。上限以外的申请直接拦截 |
| 金工完成 | 走新增厂内入库的部件以累计入库达标判定；需要喷塑的部件沿用现有加工/交接状态，不强制未喷塑入库。混合路线按适用部件汇总，具体状态映射开发前核实；不把采购五金、无此工序的部件算进清单 |
| 车缝完成 | 该订单产品全部应在车缝完成的部件均已入库完成 |
| 整单汇总 | 若订单包含多个产品，先按产品各自判断，再按全部适用产品汇总；不混用同名部件数量 |
| 公共可用库存 | 已入库量减后续实际领用等出库，按实物属性、阶段及库区汇总，与生产完成进度分开 |

示例：某部件需求4000支，已入库3000支，则仓管本次最多再入1000支。累计确认到4000支后该部件完成；之后装配领走2000支，库存可用减少，但累计有效入库仍为4000支，部件不能变回未完成或重新获得2000支入库额度。另一张订单生产的同属性件可共用库存，但不能算作本订单的生产入库完成数。

若需要纠正已经确认的入库，必须有可追溯冲销，并同步检查下游已领/在途，不能直接改库存余额或任意取消已完成状态。具体纠错操作在开发前明确。

### 4.2 装配自主分次领料（已明确）

- 按部件选择领取，不强制整单、整套部件清单一次领足，不设置固定领取批量。
- 本订单该部件剩余可申请＝max(0, BOM需求－累计已领－其他有效待审核领料量)。待审核只占用额度，不冒充已领；退回或取消后按有效状态释放占用。
- 本次可申请上限＝min(本订单部件剩余可申请, 匹配属性/工艺阶段的公共库存扣除有效待领占用后的可用量)。数量继续遵守支/套的正整数单位规则。
- 来源仍是公共库存，可以使用另一订单已入库的同属性、同阶段半成品；不要求本订单先生产入库，也不选择采购批次或生产批次。
- 例如需求4000支，本次先领500支，累计已领500支，后续最多再领3500支，并同时受实际可用库存约束；不能通过新建领料单绕过累计上限。
- 待审核数量不得进入可领库存，确认出库时再次核对订单余额及库存，并发不能重复扣或超领。
- 金工/车缝“未开始、进行中、完成”属于生产进度，不作为装配全单领料门禁。某个部件缺货只限制该部件，不能阻止其余有库存且有额度的部件单独申请。

车缝按套核验时，共用同一面料的多个部位需要汇总占用投入米数，不能把同一份已领米数分别算成各部位的完整产能。只约束计划/订单投入数量，不要求仓管选择采购批次。

### 4.3 统一示例与业务边界

以订单1000把椅子为例，以下为说明规则的假设BOM，不代表修改实际BOM：

| 项目 | 单个用量 | 该部位应入库 | 已有效入库 | 无其他占用时剩余可入 |
| --- | --- | --- | --- | --- |
| 管材部位A | 4支/把 | 4000支 | 1500支 | 2500支 |
| 管材部位B | 2支/把 | 2000支 | 2000支 | 0支 |
| 车缝部位C | 1套/把 | 1000套 | 300套 | 700套 |
| 装配成品，假设订单偏差2% | 按订单成品单位 | 净需求1000把，上限1020把 | 600把 | 420把 |

各部位不能互借额度；装配从A部位领走500支，不改变A部位累计入库1500及剩余可入2500。库存余量与生产累计完成量必须分开显示。

成品允许偏差只是入库上限，不等于保证本订单有足够材料生产到该上限。半成品仍按净需求入库/领用封顶，额外成品的实际材料来源不能靠放大入库额度解决。本期不自动增发材料、不新增超领审批；投入产出核验如何与现有成品偏差规则衔接，需在开发前定稿，不能直接假定1020把一定都能登记。

订单数量或BOM用量在发生入库后变更时，建议以已确认的生产需求版本为依据：不得因编辑BOM立即无痕改变旧单上限；需求调整需核对累计已入和占用，并保留变更依据。低于已入数量的调整不得自动删账。具体沿用哪份生产需求快照须在实现前核实。

## 5. 相同半成品如何归并

沿用BOM真实信息，不新建物料档案。建议身份包含：品类、部位或明确的组合结构、材质、规格、颜色、厚度、加工后尺寸、计量单位、已完成工艺/加工阶段。字段按物料类型适用，布面不要求管径，管件不要求裁片组成。

- 相同BOM属性、相同工艺阶段、相同库区及质量状态可合并余额，不按来源订单、入库日期或生产批次分库存。
- 来源单据仅用于审计和防重复，不限制另一张匹配订单使用公共库存。
- 未喷塑/已喷塑、未车缝/已车缝、尺寸或厚度不同必须区分。
- 最终套的定义如果包含多个部件，应比较完整组合，不以同名、同面料或同颜色代替组合一致。
- 工艺阶段不同、库区不同的余额可在界面汇总展示，但实际扣库需记录正确阶段和库区。

### 5.1 入库来源分类（已明确）

- 半成品库存名称统一为“半成品”。每条入库明细必须显示来源类型“厂内入库”或“外发入库”，列表支持按来源类型筛选。
- 厂内入库明细关联内部作业计划、工序、订单产品和部件；外发入库明细关联外发单和回货记录，并显示加工厂。来源类型由真实业务入口和后端单据确定，不让操作人手动改成另一类。
- 两类明细共同显示：入库单号、收货日期、订单/产品、部件及属性、加工阶段、数量、单位、仓库/库区、操作人、状态、备注和来源单据。厂内加工厂字段不适用，外发内部作业计划字段不适用时留空，不虚造关联。
- 来源分类只用于收发追溯，不纳入公共库存身份：相同属性、同阶段、同库区的厂内和外发产出可合并余额；领取不选来源或批次。入库明细须保留独立记录，不能合并丢失来源。
- 来源订单用于追溯及生产额度，不能限定公共库存只供该订单使用。不同加工阶段即使来源类型相同也不能合并为可互用实物。
- 历史来源只能根据可靠的原单据映射；无法识别的记录列入上线前核对清单，不全部默认标成外发。装配成品记录留在成品库存明细，不混入半成品明细；既有样品等成品来源保持原义。
- 查询直接读取有索引的来源分类、来源标识和数量汇总，记录分页、详情按需加载；不得为显示来源重新遍历采购批次链路。

## 6. 界面建议

尽量复用当前页面风格和表格布局，增加业务入口及清楚的状态：

1. 内部作业计划：金工/车缝产品行增加“半成品入库”，装配产品行增加“成品入库”，均提供入库进度和记录；裁剪不增加入库入口。仓管在这里直接办理，不要求车间先提交申请；工资报工继续独立。既有金工完成登记如何衔接另行明确，不能重复形成库存。
2. 半成品入库表单：从计划产品行自动带入计划、订单、产品、工序，按部件展示BOM单耗、订单数量、应入库、累计已入库、剩余可入库、本次数量及完成状态，同时显示已完成工艺、单位、库区、收货日期和操作人；来源自动为厂内入库。按钮“取消／确认入库”，不设置待审核列或审核操作。计划列表显示“已完成部件数/应完成部件数”。
3. 材料仓库：将“外发半成品”改为“半成品”，保留库存与入库记录查询，入库明细增加来源分类及筛选；不在这里另建一套厂内入库主入口。按阶段显示库存、待领占用、可用量；阶段名称随最终工艺路线确定，物理库区沿用已有配置。
4. 生产领料：保留原材料与半成品分区，仅显示当前工序允许领取的阶段；显示订单需求、已领、待审、剩余可领及库存。
5. 外发：沿用现有喷塑发出、回货及入库操作；统一半成品记录中补充外发来源标识和原单链接，不新增未喷塑半成品出库来源或新的外发表单。
6. 装配成品入库表单：从计划行带入订单、产品和单位，显示需求数量、累计有效入库、剩余可入库，填写实收数量、有效成品仓库位和适用包装字段；入库记录可从装配行及成品库存查看同一张单。既有成品入库校验须复用，不因为新入口漏掉库位容量、状态或单位校验。
7. 权限：仓管取得内部作业计划必要的列表/详情查看和对应入库权限；车间人员可查看允许范围内的进度，不因能打开计划页就获得入库权限。不给仓管额外的排产修改、工资或工价权限；前后端均校验计划、工序与订单归属。

开发前先核对当前页面；仅新增列/按钮能承载时做局部调整。新增厂内入库页面若明显改变操作流程，先提供页面设计给用户确认，再开发；现有喷塑流程不新增页面。不能把本讨论稿视为图稿已确认。

## 8. 历史数据与风险

2026-09-28实施状态补充：本轮已在独立开发副本完成S3实际服务/API及兼容回归、S4金工和S5车缝页面接入。真实接口、并发及1920截图证据见[实施与验收记录](internal_receipt_implementation_20260928.md)。S6装配成品入口、包含装配的S7完整业务验收、S8主环境准备与启用仍未完成，不能将本轮半成品验收视为全部方案完成。

- 已领料不能自动视为已完工，已完工不能自动视为已收货。不能用计划数补齐历史库存。
- 既有金工直接交接在途不得再次记入可用仓库；须区分未交出、已交出、已回货及已领用，防止重复形成库存。
- 已按计件报工登记的多道工序数量不能简单相加生成完工量；需有一次可识别的终结工序产出登记。
- 已入库记录建议不能直接修改数量；发生错误先制定可追溯纠正方式，不直接回写余额。此规则和历史接续方式需在上线前明确。
- 新半成品阶段会增加车间交仓和仓管确认工作；换来下一环节有据可领。权限、人员及库区配置需在试跑中核实。
- 未定项集中说明：成品净需求达标后的完成显示与偏差内继续入库；投入产出及需求版本校验；历史在途、已有库存与纠错冲销的接续。金工喷塑沿用现有流程、仓管直接确认均已确定，混合路线进度汇总需实现前核对。以上待定事项不伪装成用户已确认。
