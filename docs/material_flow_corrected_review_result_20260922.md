## 4. 外发与领料：已核实的前置缺口

### 4.1 排产来源尚未建立

HT26001 当前为 READY，但本产品 `28b7af07-b35b-4ca6-bfcf-662fc1e6afda` 没有有效排产产品记录。裁剪、车缝、丝印、喷塑四类外发来源查询均无匹配计划。因此当前无法从实际外发入口进入该产品的加工明细选择，更不能据此声称床面外发候选已通过。

领料新增页明确要求从金工、裁剪、车缝或装配作业计划发起；没有绕过该入口。后续需先确认实际工艺及排产方案，不能为了验收编造排产。

### 4.2 库存与半成品

领料需求只读接口中：车缝车间能得到布料 183.7500 米及杯托 105.0000 个，两项可用库存和最多可领数量均为 0。本产品的三个开放车间均无可领半成品行。床面半成品还不能领取；“BOM 已配置”不等于“半成品已回库”。本轮未创建回货或补库存。

### 4.3 管材提示的具体原因

金工与装配车间接口分别返回相同五条管材阻断。查验 `apps/material_issues/material_flow.py` 的 `pipe_specs` 条件后，独立只读确认：

- 五条 BOM 管材均解析到原料 5000100001～5000100005，分类为“管材”，库存单位均为“根”。关联本身有效。
- `ProductionUnit` 中没有有效“支”单位，进一步查询名称含“支”的全部记录也是 0 条。
- 现行校验把单位缺失与原料关联问题合用同一提示，因此五条同时显示“管材须关联有效根制原料及支单位”。

本次具体阻断来自基础单位缺失，不需要把原料库存“根”改成“支”，也不是旧管材库存转换。本轮未新增单位。即使后续补齐“支”，仍须重新查询，不能提前保证其他前置条件全部满足。
