## 3. 单位、计算与库存规则

### 3.1 统一术语

| 名称 | 含义 | 单位 |
| --- | --- | --- |
| 切割长度 | 一支该部位管件的长度 | mm，正整数 |
| 单耗 | 一个成品所需该部位的支数 | 支/成品，正整数 |
| 每根切割支数 | 一根原材料按该部位能切出的支数 | 支/根，正整数 |
| 原材料长度 | 每根定制原材料的采购及库存长度 | 米/根，向上保留两位 |
| 采购根数 | 原材料采购数量 | 根，正整数 |
| 采购米数 | 根数乘每根原材料长度 | 米 |
| 管材半成品 | 外发加工后已回库的对应部位 | 支，正整数 |
| 裁片半成品 | 对应单条裁片明细的一套 | 套，正整数 |

“根”只表示完整原材料，“支”表示该部位管件；界面、接口快照、打印和导出均不得混用。

### 3.2 管材公式

令订单产品数量为 Q、该部位单耗为 U、切割长度为 L（mm）、每根切割支数为 K：

```text
订单净需求支数 D = Q × U
未取整单根长度 = (L × K + 50) ÷ 1000
原材料单根长度 M = 未取整单根长度向上保留两位小数
建议采购根数 R = 向上取整(D ÷ K × 1.01)
建议采购米数 P = R × M
该部位订单原材料额度 = R 根，等价于 R × K 支及 R × M 米

实际采购根数 A 由采购员填写，必须为正整数
实际采购米数 = A × M
采购明细金额 = 实际采购米数 × 每米单价

申请外发/原材料领料支数 S 必须为正整数，且 S ÷ K 必须是整数
实扣根数 = S ÷ K
实扣米数 = 实扣根数 × 原发料批次单根长度
```

执行要求：

1. 后端使用十进制定点计算，禁止使用二进制浮点或四舍五入代替向上取整。前端预览须与后端结果一致，后端结果为最终依据。
2. 根数只在最终公式处向上取整，不先将 D÷K 取整再增加 1%，不按不同部位汇总后取整。
3. 金额继续使用项目币种和金额精度规则；不能把长度的向上取整规则用于货币金额。
4. 库存按批次冻结单根长度；BOM 后续修改不能反向改变已确认单据或在库批次。
5. 若实到长度与定制长度不符，拒绝直接按旧换算入账，提示先核实单据；本期不自动接受标准长料替代。
6. 未识别的单位、零/负数、非法小数、超字段上限和缺少切割参数均阻止确认，不按 0 或 1 静默兜底。
7. 实际采购量高于建议量不自动扩大订单领料额度；低于建议量时，实际可用库存仍是出库硬限制。改变订单额度需有 BOM 或业务规则变更依据，不能修改采购数量绕过。

计算样例：

| 条件 | 预期结果 |
| --- | --- |
| L=331 mm，K=3 | (331×3+50)/1000=1.043 米，原材料长度为 1.05 米 |
| Q=1000，U=2，K=6，L=500 mm | D=2000 支，M=3.05 米，R=337 根，P=1027.85 米，额度=2022 支 |
| 上例申请 2000 支 | 不能被 6 整除，阻止提交；提示相邻可选数量 1998/2004 支，不自动修改用户输入 |
| 上例申请 2004 支 | 实扣 334 根、1018.70 米；仍须核验剩余额度与实际合格库存 |
| 上例厂内已领 600 支 | 原材料额度最多剩 1422 支；外发不能再次领取完整 2022 支 |
| 上例退回原批次 2 根 | 原材料恢复 2 根、6.10 米，并按来源恢复对应净发料额度；不是新增 12 支半成品 |

### 3.3 面料与裁片

1. 原材料需求使用米。面料 BOM 单个用量乘订单量生成建议米数，实际采购仍允许差异并需说明原因。
2. 裁片明细需明确关联一个稳定面料 ID、颜色/规格、每套耗用米数及成品所需套数依据。不能根据名称相似自动建立关系，不能默认一套等于一片。
3. 外发材料数量输入米，另显示预计加工套数。预计套数是生产参考，不是已回库库存。
4. 对单条裁片明细及其加工分配，预计套数＝向下取整(本次面料米数÷每套耗用米数)。预计余料＝发出米数－预计套数×每套耗用米数。
5. 例如 100 米、1.5 米/套，预计 66 套、余料 1 米。实际回货按验收的合格套数和不良套数分别登记。
6. 一份座布和一份靠背布不能合并为一个库存身份；同一面料用于多个裁片明细时，各明细必须有材料分配记录，不能重复使用同一份发料米数。
7. 预计余料不自动记为损耗。部分仍在厂、退回、实际消耗或损耗均需明确处理；不得用“米数减套数”做结算。
8. 面料米数沿用项目已有受控数量精度，不擅自套用管材单根长度的两位精度。每套用量缺失时阻止换算，不能自动补为 1 米。

### 3.4 普通材料

五金、塑料、辅料继续使用自身单位及单个用量。以件、支、套等不可拆分单位管理时校验整数；以米等连续单位管理时允许合法小数。包装等未要求改变业务公式的分类只统一 BOM 编辑入口，并回归原有数量逻辑。

### 3.5 原材料额度与半成品库存分开

- 管材按稳定的订单、产品/部位来源及切割方案分别计算贡献，再形成订单可用额度；不能退化为仅按物料名称合并换算。
- 公共库存可以复用已有跨订单领用能力，但必须满足原料身份、规格、单根长度、品质、库区和批次条件。不能借用另一订单的需求额度。
- 净原料占用＝已确认厂内原料领用＋已确认外发原料发出－已确认外发未用原料退回。
- 合格和不良半成品回货、加工损耗、报废均不恢复原材料额度；只有真实未用原料退回恢复相应净发料占用。
- 草稿、待审核状态不扣库存。确认时必须在事务内再次检查额度和库存，不能依赖打开弹窗时的旧数字。
- 半成品领用只减少该半成品的合格可用余额，不再占用或扣减一次原材料额度。管材半成品可领 1 支，裁片半成品可领 1 套。
- 厂内原料领出后为生产消耗，本期不新增厂内半成品入账。

## 4. 外发、回货、退料与结清

### 4.1 发料

沿用现有外发来源、加工厂、工艺和排产关系，不创建与当前业务重复的新订单入口。加工对象和实际投入材料分别记录。

- 管材：支数输入；明示 K、单根米数、实扣根数、实扣米数、订单剩余额度和库存批次。不同部位分别换算；每个实际发料批次必须能扣整根。
- 面料：米数输入；明示每套用量、预计套数、预计余料和对应裁片明细。
- 加工厂分配须与实际发料来源对应，不能只校验全单合计而让一个加工厂拿到不完整管材根数。
- 已确认发料同时保存输入数量、库存数量、换算参数、BOM 版本、来源批次、操作人和时间。
- 原料真正从仓库发出时一次扣减；回货时不再扣原材料。仅保存外发单不扣库存。

### 4.2 回货与退料

- 合格回货进入对应半成品合格库存，不良回货进入不良库存；都不写入成品库存。
- 管材回货单位为支；裁片明细回货单位为套。分厂、分批、分部位统计累计回货，不混用米、根、支、套。
- 原料退回是独立业务动作，关联原发料记录；管材只接收整根并恢复原批次根数、米数，面料按米恢复。
- 退料累计不能超过该来源尚未消耗、尚未退回的原料。不能既把同一份材料计入加工消耗，又全额退回。
- 回货、退料支持重复请求保护，重复点击不能增加两次库存。

### 4.3 损耗、报废和完成门槛

结清至少保留两组独立记录：原材料去向记录与加工产出记录，不能直接用不同单位相减。

| 记录 | 必须表达的事实 |
| --- | --- |
| 原材料去向 | 已发数量、已退原料、投入加工数量、独立登记的原料损失、仍在厂数量 |
| 加工产出 | 合格回货、不良回货、确认的加工报废、尚待加工/回货数量，以及与加工投入的换算依据 |

实施时将原料损失与加工报废区分，避免同一损耗同时扣两次。50 mm 已是每根工艺预留，不能在库存中再额外扣一遍长度；1% 是可用备料，不是自动报废。

完成操作必须检查所有工厂、所有明细的原料去向和加工结果均已解释，仍在厂及未处理差额为零。损耗/报废须填写数量、单位、原因、确认人和时间；按现有角色体系配置后端权限。不良品若已实物回库，后续处置不能再重复增加报废回货数量。

采购米价不代表加工费计价单位。本期不扩展财务核算或应付结算；技术预检须检查原外发加工费是否与“套”硬绑定，若管材改为支后存在收费规则冲突，单独向用户确认，不能擅自按元/支或元/米换算。

## 6. 数据结构、接口与事务改动

本节是实现约束，具体新增字段名及迁移编号在 S2 技术设计清单中冻结，不能凭本文预造已存在的字段。

1. **BOM 及来源快照**：统一管材长度、单耗、每根切割支数、1% 余量、根数、米数；裁片记录单一面料关联及每套用量。旧字符串必须严格解析校验，非法旧值列入待处理，不静默取整。
2. **采购明细**：区分建议根数/米数、实际根数/米数及元/米单价；保存来源版本。采购确认、模板和打印共用同一口径，不能仅改表头。
3. **原材料库存批次**：冻结物料身份、单根长度、根数、米数、库区、品质与来源单据。入库事实数量不当成剩余数量递减；剩余量由余额和流水管理。
4. **原材料出入库流水**：记录变动根数/米数、前后值及支数输入快照；管材每笔均满足根数×单根长度＝米数。根和米同一事务变更，不能一项成功另一项失败。
5. **半成品库存**：复用现有订单产品、BOM 部位、工艺、颜色、品质和库区身份；单位改为实际支或套，保留回货厂商和批次追溯。
6. **订单需求和额度**：保留各部位换算证据，外发和厂内领料共享余额；原料退回须与原来源对应并恢复净占用，不能重建需求时清空累计已发。
7. **原料退回与损耗/报废**：新增必要业务记录及服务，明确来源、数量维度和状态，不能只在备注中填写数字。
8. **并发控制**：沿用 Session、CSRF、ETag/If-Match；复用统一锁序，稳定排序锁定批次及余额；先取唯一 ID 再加行锁，避免 DISTINCT 与 FOR UPDATE 冲突。
9. **一致性**：一次整单确认应原子提交，失败无部分扣库。重复请求只返回同次处理结果，相同请求号不同内容必须冲突。
10. **权限与错误**：后端校验查看、编辑、确认发料、回货、退料和报废权限；错误指明具体明细、单位、可用数量及原因，不以按钮隐藏代替后端限制。
11. **契约同步**：API、序列化校验、前端类型、打印导出及接口说明一起更新；只新增必要前向迁移，不修改已执行历史迁移。
12. **规格复用**：具有相同原材料身份和长度的库存批次可以按已有库存规则使用，但需求贡献保留部位身份，不跨部位共享或重复消费同一根。

## 7. 旧业务清理与采购重置

### 7.1 最终范围

这是一项**单独确认、单独演练的一次性业务重置**，不是本轮已执行动作。用户已确认业务范围，执行前仍按分步约定提交具体清单和备份证据。

| 对象 | 操作 |
| --- | --- |
| 全部旧外发单，包括已完成 | 删除本材料链路业务单、分配、发料、回货及其依赖业务记录 |
| 全部旧生产领料单，包括已出库 | 删除本材料链路业务单和明细；处理关联需求已发量，避免遗留占用 |
| 全部旧材料到货/入库及质检 | 删除材料链路记录及关联采购退货；包括生产和打样来源 |
| 原材料库存 | 本次材料链路全部清零，包括打样采购材料；不是仅管材归零 |
| 外发半成品库存 | 合格、不良余额及对应可参与业务的旧批次均清零 |
| 库存流水和批次分配 | 按清理清单处理相关依赖，使旧流水不能重新汇总生成已清零库存；不能只改余额不处理来源 |
| 生产采购单和打样采购单 | 保留编号、主体及合法来源关联，均恢复待重新确认；清除旧确认/完成事实及执行进度 |
| 旧管材采购行 | 清空旧单价和金额，生产来源按新 BOM 重算根数、米数；不能自动转换旧元/根价格 |
| 非管材采购行 | 保留合法资料及价格，不擅自清空所有材料价格；执行进度重置，数量和来源重新校验 |
| 旧供应商采购表 | 按 R27 删除，当前快照为 36 份；实际执行前重新核对清单及依赖，不自动删除供应商、模板或上传文件 |
| 成品、已制成样品、样品成品库存及其出入库 | 保留，不清零、不删除 |
| BOM、销售/生产订单、排产、供应商、加工厂、仓库、库区、员工等主数据 | 保留，不因本次清理级联删除 |
| 系统审计、清理备份、清理清单及执行报告 | 保留；业务数据清理不等于删除操作审计 |

### 7.2 采购“待确认”的技术含义

当前采购状态模型使用 DRAFT（草稿）、SUBMITTED（已确认）、PURCHASING（采购中）、COMPLETED（已完成采购），未发现独立的“待确认”状态。

本方案将“退回待确认”落实为**恢复 DRAFT，使采购单可编辑并必须重新确认**，在说明和页面中表达待重新确认，不新增一个含义重复的状态。不得只改页面文字而仍允许按已确认单据入库。

重置时同步检查确认人/时间、完成信息、版本、金额汇总、到货/退货/入库进度、来源校验值，以及已生成的供应商采购单及其发布快照。旧已发布采购快照不得继续作为改版后入库依据。

供应商采购表按已确认 R27 删除，其图片、采购申请分配、PDF 引用等实际依赖必须列入 S8 清单。用户已授权删除旧采购表，不是自动删除供应商、合同模板、上传目录或外部已签文件；实际文件处置须列出具体对象和影响，不能静默级联扩大。

### 7.3 打样来源的特殊处理

- 打样采购没有生产 BOM 时，不能伪造生产 BOM，不能直接套用其他产品切割参数。
- 管材新单价均需重新填写；样品管材根数、米数必须由真实样品用料来源及有效长度参数重建。缺失项显示待补齐并阻止采购确认。
- 打样缺料申请、采购来源绑定、到货与品质回写均需同步核对，保证重新入库只回写一次，不保留“旧采购已全部到货”的派生结论。
- 保留已完成样品的实体、图片、样品库存及业务历史；重置材料采购不应自动把已完成样品改回未制作状态。
- 如当前状态门禁不允许保留样品已完成状态同时重开材料采购，S1 必须列出真实状态冲突并逐项向用户询问，不能绕过门禁或回退样品成品。

### 7.4 清理实施约束

1. S1 先只读列出真实表、关联关系、单据 ID、状态、来源和数量；`全部`须落实成明确的目标集合，不能用数据库整库清空代替。
2. 确认范围内也要检查无采购来源的手工材料入库、质检不良、其他材料消耗及跨模块引用；未识别的来源先列出，不猜测归属。
3. 清理前备份目标数据库，记录文件大小、时间和校验值，在独立数据库验证可恢复；只有备份文件存在不算通过。
4. 在恢复副本上完整演练清理、采购重置及新流程启动，核对保留对象数量和数据摘要不变。
5. 提交实际删除/更新对象数量、主要 ID 清单、保留对象、阻塞项、恢复方案供用户确认 S9。
6. 正式执行前限制材料链路写入，复核清单未漂移；有新增或变更须刷新清单，不在变化中的数据库盲删。
7. 使用限定对象范围的维护流程和事务处理，按真实依赖顺序操作；不得关闭外键、绕过审计触发器或无条件级联删除整表。
8. 全量库存流水如与不可变审计或其他保留业务发生冲突，停止该项并报告具体引用；不得将“删除”暗中改为隐藏，也不得为了完成删除去破坏保留业务。
9. 清理后复核原料及外发半成品为零、来源不能重建旧余额、采购待确认、无孤立关联、成品及样品成品不变。
10. 旧浏览器页面和旧请求须失效或收到冲突，不能在清理后以旧来源重新扣料或入库。
11. 不自动对真实库整库回滚覆盖清理后新增业务；恢复须在停止写入、确认范围后执行。清理报告保留前后对照和操作者。
