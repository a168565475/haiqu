- 图 2：`qa/direct_handoff_design_20260922/02_handoff_return.png`，加工件交接、喷塑回货及半成品领料衔接。

图稿均为 1920×1080。参照已查看的实际 S7 领料页面及现行样式，保留 230px 深色导航、暖白底色、橙色按钮和公共窗口风格；输入控件为 32px。两张图的下半区将两个独立弹窗并列用于审图，实际业务操作每次打开一个弹窗，不在正式页永久嵌入两张表单。

## 2. 图 1：登记和备注结清

页面从现有金工计划／已出库领料详情进入，不新增一级导航。来源表按领料明细及部位列出已领、已完成、已交接、待外发占用、可外发、来源状态；查看原料根数、米数只用于追溯。

| 操作／状态 | 图稿及交互要求 |
| --- | --- |
| 登记完成 | 选具体已出库领料明细，填写正整数合格支数和完成日期，显示本次最多可登记；不填报废，不自动报工计薪 |
| 备注结清 | 显示实际已领／已完成／已交接和两类差额；备注必填，去除空格后非空，上限 1000 字 |
| 有差额结清 | 示例 210 已领、200 已完成、180 已交接，未完成 10、完成未交接 20；备注结清后实际数字不变，可外发为 0 |
| 存在待外发分配 | 显示关联外发单及占用数量，结清按钮不可用，先处理交接或取消分配，不暗中取消外发单 |
| 已结清 | 显示结清前差额及备注；登记与结清按钮不可用，不提供重开／删除入口；正式详情须显示操作人、时间 |
| 无权限 | 可查看，操作按钮不可用；正式接口也必须独立验证权限 |
| 无来源／加载失败 | 明确提示先领料或重新加载；读取不生成来源记录 |
| 提交失败（文字补充） | 保留填写值，显示失败原因；版本已过期则提示刷新核对最新数量，不能默认为成功 |

在原型中点击不同来源行，可查看有占用、已结清等状态；完成登记和备注结清仅改变浏览器内的示例状态，刷新或“重置示例”即恢复。

## 3. 图 2：外发、回货和后续领料

页面明确来源为“厂内加工件”，与现有“原材料直接外发”分支区分。加工件依据完成登记选择，按工厂、部位分配支数。保存分配占用可外发量，确认交接转为已交接，不产生第二次原料根米扣减。

| 操作／状态 | 图稿及交互要求 |
| --- | --- |
| 选择完成记录（文字补充） | 筛选同任务、产品、部位且未结清的有效完成记录，显示原领料与可分配支数，排除已占用数量；图中展示已选结果 |
| 工厂分配（文字补充） | 使用该外发工艺的有效加工厂候选，按部位填写分配量，各厂合计不超过可分配支数；不能用采购根数或米数作分配量 |
| 确认交接 | 显示完成量、本单占用和剩余可分配量；交接数量应与保存分配一致，变化时先调整分配；原料扣减明确显示 0 根／0 米 |
| 回货 | 按实际交接支数限制累计回货；合格／不良分别入对应库区，不良填写原因，不计为报废 |
| 分阶段展示 | 图中左侧为 180 支待交接，右侧为该批交接后的回货预览；实际确认交接前，回货按钮不可用 |
| 原料追溯 | 原领料 210 支、30 根、88.80 米保留；喷塑交接 180 支时不再次换算扣根米，不要求 180 为整根切割倍数 |
| 半成品领料 | 原型“预览领料分区”可打开原材料／半成品分区示例，合格 178 支、申请 100 支、预计结余 78 支；不良 2 支不计入可领量 |
| 数量异常 | 超量、小数支、合格与不良合计超过可回量、空库区或缺少不良原因均阻止确认 |
| 重复及失败（文字补充） | 提交中禁用按钮；成功后锁定本次操作；超时重试使用原请求标识，先核对结果，不能重复交接或重复入库 |

图 1 和图 2 是不同业务阶段示例，不是同一时刻的两个同步页面。图 2 后续回货窗口及领料预览不表示实际已入库；原型没有业务接口。

加工件未喷塑退回仍不能使用原料整根退回入口。两张主图未展开退回单、来源已结清后退回的重新分配等交互；这些是 P4 前必须列清的具体范围，不能据图中正常交接链路默认已支持，也不能通过备注结清把在途退回改成库存增量。P3 的登记与备注结清可独立实施；P4 未画的退回分支须补齐交互清单后确认。

## 4. 已执行验证及边界

独立本机静态服务仅提供原型、两张图片和本地字体，禁止写请求；没有连接业务 API、没有使用业务账号、没有安装依赖或更改应用源码。

实际执行 `verify_design.cjs`，31 项原型检查通过，页面错误 0、业务写入请求 0。覆盖：

- 两张图 1920×1080，无页面横向或纵向溢出；单行输入 32px；两个主窗口关键内容完整显示。
- 超已领、零／小数支拒绝；合格完成数量更新正确。
- 空白备注拒绝结清，有效备注允许保留差额结清；结清保留 200 已完成和 180 已交接，可外发归 0。
- 有待外发占用不能结清，关联单号可见；已结清禁止新增登记。
- 无来源、失败重试及无操作权限状态。
- 交接与分配一致、交接前回货不可用、不重复扣原料、回货合计上限及合格半成品领用上限。
- 1202×912 原型无横向溢出，两个窗口改为上下排列。

初次检查图 1 内容高 1111px；将表格数据行内边距调为适合 32px 按钮的紧凑间距后恢复 1080px。视觉复查图 2 时发现交接说明需要滚动，已调整窗口高度及内部间距，最终两侧窗口均无需滚动即可看到关键字段、说明和按钮。修正后完整重跑 31 项检查并逐张查看最终 PNG。

以上仅证明设计原型的显示和示例交互，不能代替正式功能、真实 API、数据库事务、迁移、权限或库存验收。后端测试未运行；因为本次未修改业务代码，不把原型检查报告为业务功能通过。
