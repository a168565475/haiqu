## 1. 本次结果与范围

管材路线：金工领原料 → 选择具体已出库领料明细登记合格完成支数 → 从已完成且未交接数量中安排喷塑 → 车间直接交给喷塑厂 → 喷塑回货按支入半成品仓 → 装配按支领用。

| 已确认事项 | 本次实现边界 |
| --- | --- |
| 原料根、米扣减 | 只在首次金工领料确认时执行，继续按整根换算并占用原料额度 |
| 加工完成 | 金工先登记实际合格支数，选具体已出库领料明细及部位；累计完成不超过对应已领支数 |
| 直接交接 | 不建立喷塑前半成品仓余额；外发按加工件实际支数交接，不再扣根、米或原料额度 |
| 数量追溯 | 订单、产品、部位、领料明细和原料批次保持关联，根、米只供追溯 |
| 报废 | 本期不新增报废明细、报废单、成本处理或损耗分类 |
| 人工结清 | 用户允许有备注即可结清；保留实际数量及差额，不把差额伪造为完成、外发或报废 |
| 面料 | 全部厂内裁剪、厂内车缝，继续按原规则领米数；不新增厂内裁片仓库入出账 |
| 既有流程 | 原料直接外发、已有外发报废及库存历史保留，不能全局跳过原有校验 |

本次备注结清按本轮讨论对象，设计在新增的金工加工／直接交接来源上。它不会连带结束已发出的喷塑订单、采购单或整个生产任务。现有外发单的结清规则是另一独立流程，本次不因一句备注而全局放开；若要把同一方式用于外发在途差额，须列为该流程的明确调整范围。

## 2. 数量与备注结清的具体设计

每条已出库管材领料明细建立唯一加工来源；登记多次完成数量也不能生成重复来源额度。

| 符号 | 含义 |
| --- | --- |
| L | 来源已实际领用的可加工支数，取已出库领料快照 |
| C | 有效合格完成登记累计支数 |
| D | 已确认交接喷塑的累计支数 |
| P | 已分配给待外发单、尚未实际交接的支数 |
| U | 未登记完成支数，U = L − C |
| F | 尚可分配交接支数，未结清时 F = C − D − P |

始终满足 `0 ≤ C ≤ L`、`0 ≤ D + P ≤ C`。原材料根、米数不参与加工件二次扣库计算，BOM 后续变化不重算原领料快照。

备注结清是人工动作，不自动触发：

1. 按具体领料明细／部位操作，窗口展示已领、已完成、已交接、待交接占用及未处理数量。
2. 必须填写非空备注，去除首尾空格后仍不能为空；沿用项目常见备注上限 1000 字。不另加报废审批流程；仍校验操作权限和当前单据版本。
3. 结清前核对待外发占用 P。若还有待外发单关联，显示单号，先确认交接或取消该分配，避免留下无法执行的单据；不能由结清按钮暗中取消关联单。
4. 结清时保存 `L/C/D/P/U/F` 快照、备注、操作人及时间；未加工和已完成未交接数量分别保留为结清差额，不合并为报废数量。
5. 结清后该来源不再新增完成登记或外发分配，可用交接量显示 0；结清前的差额在详情永久可查。已实际交接的 D 对应喷塑单继续回货、入库，不随此动作结束。
6. 不改原领料支、根、米，不恢复或再次扣减原料库存及原料额度，不增加半成品库存，不计报废、不产生费用或员工计件工资。
7. 本期不提供已结清来源随意重开／删除入口；后续如需纠错，另行形成可追溯方案，不直接改库。

具体例子：来源已领 210 支，已登记完成 200 支、已交接 180 支、无待外发占用。窗口显示未完成 10 支、完成未交接 20 支；填写备注后可以结清。历史仍显示 210／200／180，差额 10／20 保留，后续不再允许从该来源外发这 20 支。原料扣库仍只有原来的那一次。

以上结清对象、关联待外发限制及数量展示是本方案的具体设计，随整份方案确认；“有备注即可结清”不等于绕过重复请求、越权、过期版本或超量等基本校验。
