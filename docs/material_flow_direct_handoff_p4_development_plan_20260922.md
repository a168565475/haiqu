## 1. 本期目标与边界

本期只处理“金工已完成管材 → 喷塑外发 → 未喷塑退回／重新加工 → 新外发 → 合格半成品回货 → 按部位领料”的闭环。原材料根数、原材料米数、金工原始领料额度和旧外发单的历史不能因为退回、回货或结清被恢复或重复扣减。

已确认的业务边界：

| 范围 | 规则 |
| --- | --- |
| 未喷塑退回 | 仅记录退回；来源无论是否已结清都不恢复可外发量、原料根米或领用额度。未结清来源本期不再外发这批退回件；已结清来源仍可关联原单登记退回。 |
| 退回保管 | 退到金工车间暂存，登记接收人和存放位置；不进入原料库或可领半成品库存。 |
| 重新加工 | 允许重新加工，必须创建新的加工记录；原来源、原完成记录、原交接和原结清快照只读。 |
| 再次外发 | 重新加工完成后创建新外发单，可选择当前有效喷塑厂；新完成量可以拆给多个新单，但累计不得超过本次新完成量。 |
| 新单回货 | 只登记合格支数，直接进入选定的半成品库区；本期不做不良品、不良区、不良原因和报废。 |
| 新单结清 | 少回货可填写备注结清；结清后仍可追加合格回货，追加必须有原因备注；达到实际交接量后自动完成并锁定继续回货。 |
| 半成品领料 | 领料界面不选批次、不做先进先出，按可用合格半成品总量领取；不同 BOM 部位仍分开统计，不能跨部位合并。 |

不在本期：旧管材历史转换、报废、不良品流程、恢复原料库存、跨部位领用、主库迁移、前端正式接入和生产上线。

## 2. 业务对象和关系

P4 需要把“来源”和“新业务”分开，避免把退回件再次算进原来源：

1. **原金工来源**：继续引用 P3 的已完成来源、原领料明细和原料追溯快照。来源状态和结清快照只读。
2. **未喷塑退回记录**：关联原来源、原外发单、实际交接数量、退回数量、接收人、暂存位置、原因备注和时间。退回数量不得超过该外发单尚未被回货或退回占用的实交数量。
3. **重新加工记录**：关联退回记录和原来源，记录本次实际合格完成支数、完成时间、操作人。它是新的可外发额度，不修改原来源的可外发数量。
4. **新外发单及分配**：关联重新加工记录、部位、任务、产品和加工厂；允许一条新加工记录拆给多个新单。分配、实交、合格回货、结清差额分别保存，不能用原外发单追加。
5. **半成品回货记录**：关联新外发单、部位、工艺、仓库和半成品库区，每次回货独立留审计记录；库存可按同一部位聚合显示，但后台保留回货来源。
6. **半成品领料记录**：按任务、产品、部位、工艺和半成品库区扣减可用合格支数；不要求操作者选择回货批次，扣减时必须锁定该部位的总可用量。

## 3. 状态和数量不变量

### 3.1 退回与重新加工

- `退回数量 <= 实际交接数量 - 已登记合格回货数量 - 已登记退回数量`。
- 退回只增加退回审计，不增加原料根米、原来源可外发或半成品可领量。
- `重新加工完成量 > 0` 且为整数；累计新外发分配量 `<= 重新加工完成量`。
- 一支管件只能被原外发回货、退回暂存、重新加工新分配中的一个在途路径占用，不能重复分配。

### 3.2 新外发单

- 新单实际交接量必须等于已保存分配量，且不超过该新单分配量。
- 合格回货累计不超过实际交接量；少回货结清只保存快照和备注，不补库存、不生成不良。
- 结清后追加回货需要非空去首尾空格备注；原结清快照不可修改。
- 合格回货累计达到实际交接量时自动完成，完成后拒绝继续回货。

### 3.3 半成品领料

- 可领量只统计“合格、半成品库区、相同任务／产品／部位／工艺”的支数。
- 不选择批次，不跨部位合并；领料支数为正整数且不超过该部位可用总量。
- 扣减记录必须同时保存实际扣减支数、库区、操作人、时间和后台回货来源分摊结果；原料根数和米数保持不变。

## 4. 页面和交互设计

### 4.1 退回登记

从原外发单的“已交接明细”进入。页面先显示原外发单状态、实际交接、已回货、可退回上限和原来源快照，再选择退回数量、接收人、金工暂存位置和备注。未结清来源显示“本期不再外发”；已结清来源显示“来源保持结清”。保存成功后只增加退回记录，不改变原来源数量。

### 4.2 重新加工与新外发

从金工暂存退回记录进入重新加工弹窗，登记新的合格完成支数。完成后在“新外发单”页面选择有效喷塑厂，按部位分配数量，可拆分多单；每单显示原退回、新加工记录和可分配余额。新单交接前允许调整分配，交接后锁定该单的实交量。

### 4.3 新单回货与结清

回货弹窗只保留合格支数、接收仓库、半成品库区、接收人和备注。正常回货备注可选；结清后的追加回货备注必填。回货确认直接写入半成品库存，界面明确显示“合格半成品／支”，不提供不良或报废字段。实际回货达到实交量时显示自动完成。

### 4.4 半成品领料

领料页面按任务、产品、部位和半成品库区列出可用合格总量，不显示批次选择器和先进先出选项。填写正整数支数后显示预计结余；提交时提示“按支领料，后台扣减半成品可用量，不扣原料根米”。前脚管、后脚管等部位使用不同库存行。

## 5. 后端执行要求

- 所有写入使用事务；按外发单／新加工记录／部位库存行加锁后重新计算上限。
- 创建、交接、回货、追加回货、领料分别使用幂等请求标识；重复提交返回第一次结果，不重复入库或扣减。
- 使用版本号或 `If-Match` 防止页面过期覆盖最新数量；权限、组织范围、状态门禁在服务端独立校验。
- 回货和领料的库存变动必须产生可追溯事务；退回和结清不得伪造库存变动。
- 不改变 P3 的原料来源模型语义；如需新增表或字段，先在隔离数据库生成迁移并做迁移漂移检查，不操作主库。

## 7. 验收重点

1. 退回不会恢复原料根米、原来源额度或原外发单数量。
2. 重新加工一定产生新加工记录和新外发单，分配总量不超新完成量。
3. 新单只收合格品，少回货可备注结清，结清后追加回货可审计且不重开原结清状态。
4. 半成品按部位隔离；同部位可以不选批次而按总量领料。
5. 超量、零数、小数、跨部位、重复提交、过期版本、无权限和错误重试均有明确阻止或可恢复提示。
