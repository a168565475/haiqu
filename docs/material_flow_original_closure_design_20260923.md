## 2. 已确认的设计边界

| 项目 | 页面展示与操作规则 |
| --- | --- |
| 按部位核账 | 剩余 = 实际交接 − 合格回货 − 未喷塑退回。样例前脚管剩余 14 支、后脚管剩余 6 支。 |
| 自动完成 | 必须有正实交、每个部位剩余均为 0、无待交接占用；无实交不能以 0 = 0 自动完成。 |
| 差额结清 | 必填非空白备注，保存每个部位的实交、合格、退回、差额与操作者、时间。 |
| 待交接占用 | 自动完成与人工结清均须先处理占用；明确显示关联分配，不隐式取消。 |
| 后续补登记 | 两类补登都必填原因，共用各部位剩余上限；继续更新当前累计，历史结清快照与原备注不改写。 |
| 补登去向 | 合格补回进入半成品库存；未喷塑补退只回金工暂存。两者原料扣减均为 0 根 / 0.00 米。 |
| 结束边界 | 只结束该原外发单的实物流转，不关闭来源、采购单、生产任务或财务。差额结清不引入报废、不良或财务核销。 |

静态示例中的分区、暂存位置、接收人与日期用于表现界面，不是正式接口字段契约；开发时复用已确认业务接口与权限边界。
