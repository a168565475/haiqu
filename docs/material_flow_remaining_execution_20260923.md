## 3. 原单收尾规则：本次已确认

1. 各部位分别核算：剩余支数＝实际交接－合格回货－未喷塑退回，不能跨部位抵数。
2. 存在正数实际交接、每个部位剩余均为0且无待交接分配时，原单自动完成；零交接不因0＝0完成，首批回齐不提前结束仍有待交接的原单。
3. 有差额时允许非空备注结清，保存实际数量、差额、操作者和时间；不伪造完成、不记报废、不记不良品。结清前先处理关联待交接分配，不由结清暗中取消单据。
4. 结清后仍可登记合格回货或未喷塑退回，原因备注必填，两者共享原单剩余额度；原结清快照不改写，所有部位回齐后完成并禁止继续追加。
5. 合格回货进入半成品仓；未喷塑退回只登记金工暂存。均不恢复或再次扣减原料根、米。
6. 只结束所选原单的实物流转，不连带结束加工来源、采购或生产任务，不自动产生对账、费用或付款。
