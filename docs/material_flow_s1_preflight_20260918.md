## 3. 数据关系及清理依赖

已核对实际数据库外键，不仅依据 Django 默认表名推测。

1. `material_issue_line`、`material_issue_audit_event` 依赖领料单；领料行还关联订单需求和半成品余额。删除领料单前需处理子记录和净占用。
2. `outsourcing_dispatch_line` 关联材料入库行、需求、发料记录和外发材料明细。当前为空，执行前必须重查。
3. `outsourcing_return_line` 关联分厂加工分配和半成品余额；不能先删余额留下回货明细。
4. `procurement_purchase_return_line`、`sample_material_arrival` 均关联材料入库行；这是打样采购纳入清理后的必要依赖。
5. 材料库存流水通过外键关联余额；通过 `source_type/source_id/source_line_id` 标记业务来源，其中 UUID 来源不是全部都有数据库外键，必须主动核对，不能只依赖级联规则。
6. 供应商采购表关联采购单、模板版本、供应商及 PDF；采购申请分配和采购表图片还可能反向关联采购表。当前相关图片和分配为零，36 个 PDF 引用非空。
7. 中央审计使用对象 UUID 记录历史，有 `audit_log_append_only` 触发器。应保留历史引用和本次清理审计，不尝试删中央审计。
8. 排产、任务来源、样品一致性有实际数据库触发器；业务重置不能关闭这些约束来完成删除。

清理顺序只能在 S8 按最终确认清单演练后确定；本报告不提供或执行删除命令。当前没有发现材料余额/流水表上的自定义不可变触发器，但这不等于可以跳过模型限制、外键、审计或用户确认。

## 4. 计算、单位及资料缺口

### F01 管材取整是真实数值变化

- 390 条管材 BOM 明细的现有长度、单耗、每根切割支数，均可按新要求解析成正整数；本次该项异常为 0。
- 390 条的当前单位均为“根”，必须分离原材料根数、加工支数和采购米数的语义。
- 保留 1% 并改为向上取整后，190 条的建议采购根数会变化。
- 323 条实际管材采购行中，有 166 条关联到上述根数变化明细。
- 示例：`BOM0000449` 有原 102 根变为 103 根、134 根变为 135 根、179 根变为 180 根的明细。完整 ID 和新值在 `bom_profile_audit.rows`。
- 本次仅计算差异，没有保存新值。后续采购和 BOM 必须同步刷新来源版本，不能只改中文标签。

### F02 裁片与面料的明确换算关系尚未建立

- 当前有 354 条裁剪明细：351 条单位为“套”，3 条为“/”。
- 本次读取的裁片行没有 `source_fabric_material_id` 明确关联，常见来源是裁片档案 `source_cutting_material_id`。
- 当前物料档案虽区分材料/半成品，但没有在该裁片身份上直接表达本次要求的单一面料及每套耗用米数。
- 当前 `cut_piece_quantity` 不能直接当作“每套耗米”；已有样例为 2、3 等裁片数量，不能凭数量替代单位含义。
- 已确认业务规则仍然成立：一条裁片的一套只关联一种面料。S2/S4 需增加可填写、可确认的对应字段，并列出旧行补资料清单；缺资料时阻止对应换算，不按名称自动匹配。

### F03 不能把 FABRIC 枚举等同于所有行都是面料

采购快照中 FABRIC 类型存在米、个、PCS、卷、KG 等单位；当前系统使用该枚举承载多个明细分类。后续分类必须核对分区标题、稳定物料身份及现有分类映射，不能批量把所有 FABRIC 行强制改为米。

### F04 现有库存和额度需保留部位换算

当前原材料余额主要按原料、库区、单位和品质区分；没有完整的管材单根长度、根数/米数双数量约束。现有订单需求会聚合原料贡献，不能用聚合后的平均比例换算不同部位。

开发应沿用库存服务并补充批次长度及部位贡献，保持一根/一部位的切割关系；原材料和半成品使用不同余额，不为半成品再次扣原料。

### F05 外发价格与数量需要同时展示单位

当前外发页面的价格显示为 `元/当前加工单位`，金额按加工分配数量乘单价；不是旧方案描述的全工艺固定元/套。当前没有外发业务单需要迁移旧加工价。

新图必须明确区分管材“支”、裁片“套”和原料“根/米”；后续实际加工单价按对应加工单位输入，不能自动从采购米价推导。若用户实际收费单位与加工数量单位不同，在进入对应开发前再单独确认，不扩展为财务结算。

### F06 打样来源当前为空，不能把空数据当成已验收

打样材料缺料快照、采购绑定及到货回写结构已存在，但当前相关记录均为 0。清理本次无实际打样采购行可删；开发测试仍要在隔离数据库创建真实关联场景，验证重置不回退已制成样品、不重复入库回写。
