| 范围 | 修改内容 | 使用结果 |
| --- | --- | --- |
| 新建外发单 | 分离原料输入和预计产出，保留多产品、分厂、加工单价；关联对应部位原料；增加批次预选和回货计量说明 | 管材填支，显示预计根/米；面料填米，显示每套耗米、预计套数及余米。保存不扣库存，预选不占库存 |
| 来源与明细选择 | 校验当前已确认 BOM、原料身份及裁片关联；显示共享原料余量、缺参原因；读取失败可重试 | 不从旧单位比例猜管材根数，不把其他部位的面料混作同一裁片投入 |
| 仓库发料 | 按工厂、部位、批次校验整根；再次检查长度、实际库存及厂内/外发共享额度；整单事务扣减 | 402 支、6 支/根、3.05 米/根，扣 67 根 / 204.35 米。非整根、超库存或超额度整单拒绝 |
| 发料记录 | 同时保存实际支数、根数、米数、来源批次及冻结换算参数 | 详情能复核发了多少支，实际扣了多少根、多少米 |
| 分批回货 | 管材按整数支，裁片按整数套；合格与不良分库；可同时补登记本次新增实际投入 | 回货只增加半成品，原料不重复扣减；已登记投入不重复记账 |
| 原料退回 | 只能退本单、本厂、原批次中未投入/未损失的原料；管材整根退回 | 恢复原批次根/米与对应支数额度，不能重复退或超退 |
| 投入、损耗与报废 | 增加投入加工、原料损失、加工报废三类追加记录，保留原因与确认人 | 原料损失与产出报废分别计量；已回库不良不能再次计作未回库报废 |
| 结清 | 原料去向、加工产出分别对账；差额展示原因；新增明确的结清按钮 | 回货满量不自动完成；两侧差额均为零才可手动结清，不自动补损耗 |
| 权限与并发 | 新增退料、登记、结清权限；继续使用版本校验、登录会话防伪校验、重复请求保护与事务锁 | 无权限不能写；同一请求重试不重复扣/增；并发不超额、不产生负库存 |

专项覆盖：分厂、原单位五金、每批分别整根、错误批次、共享厂内额度、原料退回、部分合格/不良回货、报废、未结清阻断、过期版本、重复请求，以及两个独立连接的并发争用。面料精度用例使用三个不同发料批次各投入 1 米、3 米/套，确认合成 1 套。失效的无关库存批次不会阻断其他材料来源查询。

手工复核示例：发 12 支、6 支/根、3.05 米/根，应扣 2 根 / 6.10 米；退 1 根，另 1 根投入并回 6 支合格品，两侧对平后结清。面料发 3 米、1.5 米/套，投入 3 米并回 2 套后结清。100 米对应 66 套与 1 米余料，余米必须另行退回或登记原料损失。
