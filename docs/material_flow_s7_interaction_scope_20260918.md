## 已确认的具体界面范围（Q-S7-01=A）

| 编号 | 页面或弹窗 | 控件与使用结果 |
| --- | --- | --- |
| U01 | 新增/编辑 `/workshop/material-issues/new` 及现有编辑路由 | 按批准图保留基本信息卡；上下同时展示原材料、外发回库半成品；分别添加/移除明细。底部显示各区项数，不汇总不同单位；保留保存草稿、提交仓库审核 |
| U02 | 添加原材料与批次分配 | 用公共窗口选本产品、本车间允许的物料/部位，显示订单额度、外发已用、厂内已用及剩余。管材选择具体批次/库区，显示单根长度、可用根米；逐批填支、联算预计根米；每个部位、每批分别整根。其他原料保持实际单位 |
| U03 | 添加外发回库半成品 | 用公共窗口选择本订单/产品对应的合格半成品余额，显示部位、类型、规格、颜色、库区、可用支/套。管材填整数支、裁片填整数套；不同部位不能凑套，不要求整根倍数，不再次扣原料或原料额度 |
| U04 | 草稿、提交及退回后编辑 | 保留现有草稿/待审核/已退回/已出库状态及来源校验；草稿与待审不实际扣库。提交展示完整性、非整根、库存/额度冲突；保留输入，不自动向上取整，不自动换批次 |
| U05 | 待审详情与仓库确认出库 | 上下两区复核申请与预计实扣。确认窗口逐行显示物料/部位/批次/库区，以及支→根/米或半成品支/套；主按钮“确认出库”。确认时重新检查库存、共享额度、来源版本及权限；整单失败不部分扣账 |
| U06 | 退回申请人修改 | 沿用 AppWindowDialog 退回窗口，填写原因；展示退回人、时间及原因，申请人修改后重提。这里是审核退回，不新增已出库生产退料或撤销扣库功能 |
| U07 | 已出库详情与记录 | 原料区保存并展示申请支数、实扣根数、实扣米数及批次；半成品区保存实际扣支/套与出库后余额。读取冻结记录，不用后续修改的 BOM 重算已出库结果；保留确认人、时间、审核记录 |
| U08 | 列表、来源入口与异常状态 | 沿用现有列表筛选、状态、分页和作业计划跳转；不顺带改作业计划页面布局。页面/窗口覆盖加载、空数据、读取失败重试、无权限、非整根、库存/额度不足、过期版本、重复提交及来源失效 |

所有界面沿用当前暖白背景、橙色主按钮、32px 单行控件、现有表格及公共窗口风格；多明细在内容区滚动，操作区清晰可见。原料与半成品的分区必须对应不同库存身份，不能只是同一份库存换个页签。
