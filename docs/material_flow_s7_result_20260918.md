## 排错记录与审查

- 初期测试夹具缺少领料员必填字段、使用了不属于本项目的状态枚举、半成品回货未登记投入，均按实际模型和外发规则修正；失败日志保留。
- 管材批次日期原不能保存进 JSON 快照，已转为可保存格式；半成品部位身份原误取不存在的余额属性，已从 BOM 部位关联读取。
- 只读代码审查发现跨单并发复用确认标识可能触发唯一键错误，已在操作前按请求号加锁，并通过跨单并发测试。
- 复用已清空的并发测试库时曾出现 4 个初始化错误；夹具改为自行创建所需装配车间，最终独立重跑 4/4 通过。**`s7_concurrency_final.log` 是失败记录，最终通过证据为 `s7_concurrency_verified.log`。**
- 浏览器首次启动缺少预览服务及同源接口配置，未写业务数据；修正隔离启动参数后再做完整验收。
- 最终界面检查修正了半成品明细的库存口径文字，并使退回编辑使用当前批次余额、不沿用保存草稿时的可用量。

只读审查确认此前业务缺陷均已闭环；最后剩余的并发夹具问题已补成功证据。未新增依赖，沿用现有 Django、PostgreSQL、Vue、Element Plus 与 Playwright 环境。
