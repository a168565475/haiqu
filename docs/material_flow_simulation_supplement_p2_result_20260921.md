## 怎么执行和验证

本轮新增专用程序，未改应用业务规则或页面：

- `build_p2_payloads.py`：固定隔离库身份，校验既有有效管理员的操作权限和数据范围，构造完整七分区提交及每行精确预期。
- `run_p2_isolated.py`：按稳定顺序锁定目标及原料，校验冻结原值和 SHA-256；使用现有 BOM 序列化、保存、确认服务；对已批准采购来源显式更新并补全审计，再使用正常采购更新及来源校验。
- `verify_p2_results.py`：逐字段核对、检查原 ID 集合、保护非目标行和原料档案、保留历史审计，并复核全部有效 BOM/采购来源。
- `execute_p2.py`：只在 P1 内部网络启动一次性演练容器，业务容器仅强制只读查询。应用目录只读挂载，无对外端口。
- `build_p2_review.py`：把已提交的真实演练差异整理为人可读清单，不连接数据库。

脚本位于 `qa/material_flow_simulation_supplement_20260921/`，无新增依赖。数据库名、主机别名和 PostgreSQL 实例标识均须符合冻结身份；不能通过换环境变量将 P2 程序用于业务库。
