# 第 1 步结果：已出库生产领料详情提速

日期：2026-09-28。状态：第 1 步已完成并在当前本机服务验证。后续公共库存及半成品共用尚未实施。

## 改动及原因

实际应用代码仅修改 `src/backend/apps/material_issues/api/serializers.py`：

1. 已出库原料明细的 6 个数量快照字段完整时，直接返回历史值，跳过实时库存和批次候选扫描；合法零值原样保留。
2. 快照缺失或缺字段时，保留既有逐字段回退；草稿、待审核和退回单仍读取实时库存。
3. 明细和审核事件在已预加载的对象上按原顺序排序，避免重新查询造成关联缓存失效。

查询选择器原有预加载已经足够，本步无需修改它。新增 `src/backend/apps/material_issues/tests/test_material_issue_detail_loading.py` 作为回归保护。

没有修改库存扣减、订单额度、批次写入、半成品归属、状态、权限、单位、前端布局或超时设置；没有改数据库模型及迁移。本步不增加依赖。
