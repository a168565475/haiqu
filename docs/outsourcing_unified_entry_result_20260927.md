## 权限与异常处理

- 普通外发范围与金工来源范围分别授权，再按单去重合并；同一账号有两类权限时，也逐单判断能否看到普通完整摘要。
- 仅金工来源可见的原单只汇总可见来源；整单收尾继续校验全部来源权限，任一来源无权访问时不放行。
- 产品名称／货号搜索仅匹配普通可见范围的冻结产品字段，不利用隐藏产品字段让受限来源订单被搜索命中。
- 未首发单显示待选择；来源已结清、没有可外发数量、定位失效、接口失败、版本冲突及不确定保存结果沿用对应阻断与重试处理。
- 本轮不新增业务表、迁移或写入接口，不修改原库存事务与单位换算规则。

## 使用路径

1. 打开“生产车间 → 委外加工”，在“外发单”统一查看和筛选。
2. 在“待外发材料”登记加工完成、查看来源历史或办理来源备注结清。
3. 点击“新建外发单”，选择实际材料来源后继续填写。
4. 点击对应单据“查看详情”办理后续业务；金工原单的计划明细在“外发明细 → 计划与数量核对”中展开，交接和回货按钮优先展示。

环境继续沿用项目Vue／Django／PostgreSQL和现有依赖，无需新增安装。当前为本机开发应用，未执行正式生产环境部署、Git提交或推送。
