## 实现边界

- 每项操作分别合并角色的资源选择，空列表表示无可访问资源。查看全范围不会扩大编辑范围。
- 使用真实 Workshop/Craft ID；不按角色名称判断，不通过前端隐藏代替后端过滤。
- 工艺受限授权只提供该业务入口所需的局部关联摘要，不自动授予独立生产订单、排产或领料 API。
- 金工来源自身没有工艺归属：工艺受限查看仅返回与授权工艺存在原交接或新外发实际关联的来源。来源数量仍为共享来源总量，不按可见关联重算库存或占用。无关联来源需要显式通用来源查看权限。来源级完工和结清不提供工艺范围，以免对共享总量进行局部授权写入。
- 历史直接授权、分组与员工车间授权保留原语义；正式配置前仍需查看有效权限来源，不能承诺新角色自动收窄旧授权。
- 新迁移为 access_control.0006；`ACCESS_RESOURCE_SCOPES_ENABLED` 默认关闭。管理页及有效权限查询在关闭状态不访问新资源表。本轮只在隔离数据库迁移、授权和写入测试数据。

## 验证记录

- 新增权限范围后端用例 19/19 通过，覆盖按操作合并、空范围拒绝、真实资源校验、保存/复制/审计、样品工序越权、车间上下文，以及新旧授权混用时的工艺边界。证据：`qa/permissions_scopes_stage1_20260929/backend-final-resource.log`。
- 前端定向测试 25/25 通过（权限单元格、样品报工弹窗、样品表单、认证 store）。本轮业务代码及有效权限来源展示完成后，`npm run build` 曾通过，包含 TypeScript 检查。窄窗口 CSS 修正后的最终构建遇到工作区其他开发产生的 `WorkshopConfigManager.vue:228` 类型错误：表单已移除 `requiredQuantityPerProduct`，但仍有旧属性赋值。该文件不在本轮修改范围，未覆盖其他工作；当前整体构建未通过，证据见 `frontend-build.log`。此前成功构建另有大包体提示。
- `makemigrations --check --dry-run` 返回 No changes detected；迁移仅用于隔离测试数据库。
- 两路代码复审发现的响应式对象深拷贝、历史授权与新工艺授权组合、共享来源操作以及查询集合并问题已修复，并由定向测试覆盖。
- 扩大回归共发现 301 项、实际运行 293 项，25 项失败及 10 项错误，不能报告为全量通过。其中外发旧测试的 25 项失败和 7 项错误，已在修改前快照中逐项复现，失败名单完全一致（`baseline_comparison.json`）；主要涉及旧输入数量字段及既有采购数量预期。其余 3 项为并发测试类与其他事务测试混跑的初始化冲突；这 3 个类的 8 项用例单独运行全部通过，证据：`backend-concurrency.log`。
- 正式库尚未执行本轮迁移，真实角色、员工授权及业务开关未因本轮调整。主服务采用源码挂载，本轮使用默认关闭的资源范围开关保护迁移前兼容性；源码变更不等于正式授权启用。

浏览器验证使用 8187 前端、8017 后端及 `test_haiqu_access_scopes_20260929` 数据库，API 仅允许测试前端同源代理。临时账号口令放在系统临时目录，不进入仓库。并发回归完成后再开始浏览器验收。
