# HAIQU ERP 业务范围与边界

本文用于帮助新窗口理解项目目前的业务范围，区分当前项目文档、历史 CRM 阶段和尚未确认的内容。它不自行新增业务规则；遇到冲突时，保留来源和时间，等待单独确认。

## 1. 项目定位

HAIQU ERP 面向户外用品外贸及工厂业务，按模块逐步建设。当前项目已经从最初的 CRM 阶段扩展到客户销售、产品物料、采购库存、生产委外、权限和基础配置等 ERP 方向。

**可信度**：`verified`（来自当前项目 README、PRD 和代码目录）；不能因此把每个模块都写成“已完成”或“已验收”。

## 2. 当前项目文档列出的建设范围

| 范围 | 负责内容 | 边界说明 |
| --- | --- | --- |
| 客户与销售 | 客户、联系人、沟通、询盘、报价、样品跟进和销售协同 | 具体字段、状态和数据范围按对应模块规则 |
| 产品与物料 | 产品资料、BOM、原料和物料相关业务 | 不由模块名称推测数量、单位或成本口径 |
| 采购与库存 | 采购、库存、入库和库存相关业务 | 实际库存、可供数量和预留口径按库存模块确认 |
| 生产与委外 | 生产任务、车间作业、报工和委外流程 | 工序完成不能自动等同于整单完成 |
| 权限与基础配置 | 角色、员工账号、团队、权限和基础资料 | 权限由后端接口和数据范围执行，前端隐藏菜单不是完整授权 |

来源：当前项目 [`README.md`](../../README.md) 的项目定位与范围、模块代码入口和对应专项文档。

## 3. 历史 CRM 阶段

`docs/haiqu_ERP_客户CRM_PRD_V1.0.md` 是最初 CRM 阶段的 PRD。它记录了客户全生命周期、客户 360 度、销售跟进、询盘、固定模板报价、轻量样品跟进、订单里程碑和商业单据追溯等背景。

该 PRD 明确把采购、库存、生产、完整订单履约、总账、应收核销和复杂 AI 推荐列为当时的非当前范围。这个结论属于 CRM 第一阶段，不能直接覆盖当前 ERP 项目 README 的扩展范围。

**处理方式**：

- 历史 CRM 范围保留，用来解释旧文档为什么没有采购和生产。
- 当前项目范围以最新项目级文档和用户后续确认的模块范围为准。
- 旧 PRD 中的字段、流程和“第一阶段”措辞不能自动当成当前所有模块的限制。
- 样品专用采购、到料、领料和库存属于当前 ERP 的样品/采购/库存扩展范围；旧 CRM PRD 中“不管理这些内容”只代表历史阶段，不是当前 ERP 的禁止事项。

## 4. 暂不视为当前已确定范围

以下内容不能因为代码、旧 PRD 或权限方案中出现过名称，就直接视为已经确定的产品范围：

- 完整财务、总账、应收核销和完整毛利核算
- 企业微信的真实身份接入和同步
- 完整订单履约流程；销售订单相关代码或权限入口不等于完整订单业务已经启用
- 公司正式销售 SOP、客户分级、信用政策、汇率和毛利口径
- 尚未经过用户确认的自动化、AI 推荐或跨模块计算规则

这些内容如要进入正式范围，必须有专项方案、来源和用户确认。

## 5. 模块边界原则

- 代码中存在页面、API 或模型，只能证明有实现入口，不能单独证明业务范围已经确定。
- 设计规范只约束界面和交互表达，不能新增字段、流程、权限或数据计算规则。
- 前端菜单隐藏不等于后端授权；权限必须同时核对账号、操作权限、数据范围和业务状态。
- 一个模块需要引用另一个模块的数据时，要记录来源、快照时点和责任边界，不能复制成两个互相矛盾的事实源。
- 历史文档、当前代码和用户新决定冲突时，不直接覆盖旧记录，先建立冲突记录。

## 6. 事实来源和冲突处理

| 内容 | 当前优先来源 | 可信度处理 |
| --- | --- | --- |
| 项目当前总体范围 | 最新项目 README、用户明确决定 | 文档事实先记 `verified`；用户明确决定可记 `confirmed` |
| 历史 CRM 范围 | CRM PRD V1.0 | 记为历史 `verified`，不覆盖当前范围 |
| 模块实际功能 | 当前代码、模型、API、迁移和专项验收 | 代码事实与业务范围分开记录 |
| 业务规则 | 用户确认的方案、正式 PRD 或模块知识卡 | 未确认内容只能是 `draft` 或 `unknown` |
| 权限边界 | 后端权限、数据范围、权限专项方案 | 不能只看菜单或页面按钮 |

## 7. 更新规则

- 项目新增或取消模块时更新本文，并记录日期和来源。
- 历史阶段不删除，改为标注历史范围或 `superseded`。
- 发现 README、PRD、代码和用户决定不一致时，先记录冲突，不静默选择。
- 仅页面尺寸、一次性实现细节或可以从代码重新生成的内容，不写入业务范围。
