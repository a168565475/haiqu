# 公共库存：本轮管材业务试跑结果

2026-09-28，用户对旧单保留、新隔离副本启用和后续32支厂内／4228支原料外发试跑回复“确认”。本轮已执行完成。**结论仅为新隔离副本的管材链路跑通，不代表主环境上线或全部生产业务完成。**

## 本轮做了什么

| 步骤 | 执行结果 | 目的和库存影响 |
| --- | --- | --- |
| 启用公共库存 | 正式启用工具将新副本从MAINTENANCE改为PUBLIC；两项临时开关仍关闭 | 采用持久状态控制；启用本身没有业务库存写入，其他255表未变化 |
| 厂内领料 | 两张新领料单合计32支，审核出库 | 扣4根、14.80米；不关联采购批次 |
| 旧在途回货 | 5项合计1166支，按已确认接续信息回公共仓 | 不再扣历史已发原料；一次同请求重放未重复增库存 |
| 原料外发 | 4228支，整根换算569根、2187.47米 | 11条实际发料记录均没有采购入库批次外键 |
| 普通材料随单发出 | 实际5项3500 PCS | 原计划6项7350 PCS中历史已领3850 PCS，本轮仅使用剩余额度；已领满的1项跳过 |
| 原料外发回货 | 分3厂登记实际投入后回4228支 | 原料投入按根登记，BOM换算支数；回货只增加半成品 |
| 厂内加工交接回货 | 32支完工、交接喷塑、合格回库 | 同属性并入已有公共库存，库存组数不增加；不重复从仓库发原料 |
| 装配领料 | HT26050领4200支，HT26001领1155支 | 合计5355支；只扣半成品，两订单对应11项剩余可领全部归零 |
| 收尾 | 3张相关外发单均COMPLETED，4张新领料单均ISSUED | 原料外发单对账平衡后结清，结清不产生额外库存流水 |

## 数量对账

- 原料期初：20446根／86217.81米。
- 本轮扣原料：4＋569＝573根；14.80＋2187.47＝2202.27米。
- 原料结存：**19873根／84015.54米**，321个库存组。
- 半成品回货：1166＋4228＋32＝**5426支**。
- 半成品领取：4200＋1155＝**5355支**。
- 半成品结余：**71支**，留在11个公共库存组中；满足订单需求后不把余量继续领给原订单。

最终只读核对332条余额、353条流水，逐条检查流水前后连续、余额与流水汇总一致、原料根米换算一致、无负库存。三张保留旧单的单头、明细、审批历史摘要仍与确认清单一致。95个冻结候选文件摘要未变。本轮仅增加试跑脚本、独立服务配置、记录和文档，没有新增产品代码改动。

## 两次被拦截的情况

1. 创建新原料外发单后，试跑脚本原先误认为普通材料7350 PCS都尚未领取，数量断言失败。核对确认其中3850 PCS历史已领；恢复流程读取已成功创建的同一外发单，仅按剩余3500 PCS发料，没有再次建单或清除历史额度。
2. 第一次原料外发回货未带“实际投入”记录，接口返回409。先确认本单回货、投入记录均为零，再以新请求按实际已发根数和普通材料数量登记投入，随后3厂回货均成功。原失败日志保留，没有自动重试，也没有为通过测试降低业务校验。
