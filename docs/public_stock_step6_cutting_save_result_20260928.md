## 改什么、为什么改

裁剪行同时绑定稳定库存来源时，保存入口会用旧来源快照覆盖用户显式提交的材质和规格。例如床面提交 PE 后仍变回 PVC，椅面提交尺寸后仍变回 `/`。另一条裁剪保存路径原本允许这些字段编辑，两条路径规则不一致。

本次仅在裁剪明细的稳定来源路径保留显式提交的材质、规格和单位，增加 7 行实现。未提交字段仍沿用既有来源快照；颜色走原有保存逻辑；新用量模式仍强制流转单位为“套”。原始来源编号、部件身份及关联面料不变，管材和面料仍由来源提供权威属性。

实际改动文件位于 `qa/public_stock_step6_20260928/isolated_backend/`：

- `apps/boms/api/serializers.py`：修正上述覆盖。
- `apps/boms/tests/test_cutting_usage.py`：新增 3 项接口测试，验证编辑后读取、来源与用量保留、省略字段、清空来源失败回滚，以及管材/面料不能伪造来源属性。

本次未添加前端、迁移或依赖，不涉及界面重新设计。

实现差异如下，位于既有来源快照调用前后：

```diff
 part_name = line.get("part_name", "")
+# 裁剪明细沿用已有编辑契约；稳定来源 ID 只固定来源，不覆盖裁片自填属性。
+cutting_values = {
+    field: line[field]
+    for field in ("material", "specification", "unit")
+    if section["title"].strip() == "裁剪明细" and field in line
+}
 self._set_inventory_source_snapshot(line, source, existing_line)
+line.update(cutting_values)
```
