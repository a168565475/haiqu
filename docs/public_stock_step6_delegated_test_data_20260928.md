2. 合格半成品回库 **10套**，保留选定的材质、颜色及2片/套信息；半成品库存单位为套。
3. 半成品订单需求按“订单数量×套/成品”计算，不因每套2片而翻倍。
4. 再回1套被409响应拒绝，库存流水不增加，原料不重复扣减。

这是Django测试客户端调用真实接口和服务，数据库操作仅发生在专用测试库，并由测试事务回滚；不是浏览器验收，也不是已将3张旧BOM修改完成。样例验证委外的米/套契约，不改变用户此前“实际试跑全部厂内裁剪”的选择。厂内裁剪/车缝身份仅在上述43项预演中核对。
