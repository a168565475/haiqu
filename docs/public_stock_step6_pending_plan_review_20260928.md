## 4. 公共模式后是否能保留草稿/退回

**可以保留，不必新增作废状态，但不能声称它们已成为完全不可编辑的档案。**

候选源码根目录为 `qa/public_stock_step6_20260928/isolated_backend/`：

- `apps/material_issues/services.py:594-638,656-709`：提交与确认分别在 602、677 行检查单据库存版本。正式 `PUBLIC` 生效后，旧 `LEGACY` 草稿/退回单不能重新提交，旧待审单不能确认出库；错误码 `PUBLIC_STOCK_LEGACY_DOCUMENT_BLOCKED`。
- `apps/inventory/public_stock_mode.py:12-56`：持久控制状态 `PUBLIC` 即启用完整公共模式；模式检查不会自动把旧单改成新版本。
- `apps/material_issues/services.py:418-450`：旧 DRAFT/RETURNED 仍允许编辑；没有同样的模式门禁。编辑可更换明细并同步旧需求，但不会直接扣库存。旧单因此是“保留且不能再执行”，不是“完全只读封存”。
- `apps/material_issues/services.py:642-652`、`apps/outsourcing/services.py:759-785`：退回/作废无需库存模式一致；但二者均受 `stock_write_transaction` 的 MAINTENANCE 停写门禁保护（`apps/inventory/public_stock_cutover.py:109-130`）。不能假定进入停写后照常调用接口处理旧计划。
- `apps/material_issues/public_issue_services.py:253-255` 仍调用同一 `sync_selected_pipes`；`pipe_requirements.py:69-110` 按产品和稳定部位身份继承原已领/已外发量，不重置历史耗用。更换已使用的原料/切割参数会阻断，不能通过复制部位绕开。

激活预检建议：所有旧待审领料及待发外发都必须先处置；DRAFT/RETURNED 可以凭明确保留清单通过。清单需绑定单据 ID、单号、版本、状态、库存模式、明细摘要、审批事件摘要和未出库证据。处置后在最终停写快照再次比对，期间变化即重新审核。PUBLIC 后禁止把模式退回 LEGACY 来继续执行这些旧计划。

## 5. 建议次序及需用户决定的事项

1. 先确认旧计划业务去向：HT26050 继续“厂内 32 支 + 原料外发 4,228 支”，还是“全原料外发 4,260 支”；不得原样同时重建。HT26001 的剩余 10、6 支是否仍需要领取也应明确。
2. 推荐处置包：两张待审原单退回并写清“公共库存切换，旧单保留，新单另建”；草稿保持 DRAFT 并登记保留凭证；旧 WF 作废并保留全部行。不删单、不重置额度、不手改单据库存版本。此包仍需真实写入授权。
3. 在持久停写之前，通过现有权限和并发门禁完成已授权退回/作废；随后进入停写、取得当次新备份与处置后证据。若状态或数量变化，停止按旧清单继续。
4. 公共激活后按确认路线新建公共计划，逐行继承历史额度、关联旧单号；先预览可领/可发量，再按正常审批执行。

协调方已确认现有 tools 副本处于 MAINTENANCE（本子任务未访问该库）。因此其当前样本必须因旧待审/待发计划未处置而被激活预检阻断；不得为让测试通过自动放行、关闭维护或手改状态。完整动作链须另建获授权的新副本，在进入停写前演练正常退回/作废后重新备份，或先评审专用受控处置方案。

相关在用 BOM 的管材喷塑色当前仍为 `/`；外发重建的身份资料需另行补齐。旧五项在途已确认的黑色磨砂只适用于原在途接续，不能自动扩展到这些未来计划。
