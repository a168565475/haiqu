# 第 6 步工具开发与隔离验证

日期：2026-09-28。版本：V0.13。正式系统尚未合入、迁移或切换。本文保留正式期初导入、旧单接续及用户 A 补证的历轮结果；后续“继续”授权的启用工具和操作包也已完成隔离验证。最新结果见 [启用工具验证](public_stock_step6_activation_result_20260928.md)，五项旧在途见 [补证及接续结果](public_stock_step6_supplement_confirmation_20260928.md)。在用 BOM 修正、旧计划处理和主环境整合启用仍待完成。

## 已实现的变化

| 工具 | 改动前 | 现在 |
| --- | --- | --- |
| 正式期初导入 | 只有固定隔离库的预演命令 | 独立正式命令，默认只读；校验目标主机、数据库、实例、管理员、备份、维护状态和清单摘要，单事务建立公共账 |
| 重复执行 | 不能把隔离预演当正式期初 | 同清单核对后返回原凭证，新增流水为 0；来源或余额改变会拒绝，已有隔离期初不能收编 |
| 旧单接续 | 切到公共库存后，旧直接交接单不能直接回货 | 新增不可变接续凭证；原领料、原外发、原交接及原出库流水保留，旧单版本仍为 LEGACY |
| 接续后的流转 | 缺少可信公共产物身份 | 依据核验的历史实物和补充颜色，沿原 API 回公共半成品；兼容原单结清后补回、未喷塑退回及再加工，不重复扣原料 |
| 切换停写 | 只有进程配置开关 | 数据库保存维护状态；收发料和相关业务写操作先取共享锁，正式工具取独占锁；27 个高层服务入口同样受控 |

旧管材按米库存仍不转换，普通料 1,047 条现有余额不复制。原料库存与订单额度的既定规则不变。相同来源分次交接，根数、米数按来源累计一次，交接支数按实际各次累加。
