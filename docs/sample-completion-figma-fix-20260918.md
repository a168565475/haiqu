# 工厂完善样品需求原型修正

实际读取 Figma 文件 `czPqlJ7fXYn5cq4cbQyTFm` 节点 `724:8929` 的设计上下文与截图，对应 `/samples/:sampleId/edit` 的 COMPLETE 模式。

## 原因与修正

- 外层 PageContainer 强制 14px 留白和 34px 大标题，导致原型 14px 飘带标题放大、固定底栏超出视口。仅为样品编辑路由取消外层留白，页面自身管理内容区；局部恢复飘带标题字号。
- 通用 `.basic-grid` 样式额外增加表单内边距，本页显式清零。保留五列、16px 列间距、8px 行间距。
- 完善页自动生成 19 行旧版“打样信息明细”，原型没有该区域。COMPLETE 模式不生成、不展示该区域，已有数据仍随保存保留。完整编辑及报工模式继续使用原有规则。
- 后端只取消完善提交的额外打样信息明细非空校验；任务单、样品明细、数量、权限、并发版本及历史财务流程不变。无新增数据库迁移。
- 标题恢复“完善样品需求”，业务员按原型只读；底栏仅保留取消和完善并提交，来源、申请人及等待时间显示在特殊说明下方。
