## 实际结果

费用三条记录均从侧栏进入打样列表，搜索申请号、查看详情，再点击费用处理：

| 方式 | 实际结果 |
| --- | --- |
| 收费 | 100 + 20 − 10 = USD 110；PNG 凭证上传和扫描通过；上传刷新保留尚未提交金额；核验状态为 EVIDENCE_UPLOADED，不冒充财务到账 |
| 免费 | 应付 0；真实确认员工和业务理由保存，核验为 NOT_REQUIRED |
| 豁免 | 提交后保持 PENDING，指定审批人审批后 WAIVED / APPROVED；刷新审批人及理由正确回填 |

物流以这次免费样 `5b660811-3ffb-40e8-8aa3-bbabd093f613` 执行，从列表详情点击物流与反馈：

1. 创建寄送记录，申请数量 2，本次实际寄送 1。
2. 使用隔离联系人与地址确认寄出，样品状态 SHIPPED。
3. 更新进度，事件类型 PROGRESS，保存完整说明且不替代寄送状态。
4. 手工签收，寄送状态 DELIVERED。
5. 记录客户正式反馈：来源 CUSTOMER、版本 1、结果 PASSED。
6. 执行确认通过，刷新后样品状态 CONFIRMED，物流事件包含 DELIVERED / PROGRESS / SHIPPED。

两个脚本均 PASS，业务请求均返回成功，页面异常为 0。1920×1080、1440×900 截图检查无文档横向溢出；新增详情入口与标题无交叠。人工查看收费、豁免、详情窄桌面及物流确认态截图。
