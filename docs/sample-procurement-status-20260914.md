# 打样采购状态区分

仓库提交缺料后，当前环节显示“等待采购”。至少一个缺料来源关联真实、未归档的采购订单行后，显示“采购中”；创建草稿订单也算已建单。无关订单不触发变化，全部关联订单归档后恢复等待采购。部分入库仍处于采购中，全部材料齐备后沿用现有参数及生产流程。

## 接口兼容

- 保留数据库流程值 `PROCUREMENT_PENDING`，避免修改已有入库权限和流程门禁。列表、详情、用料、仓库的展示文字统一由 `procurement_status.py` 决定。
- `status=PROCUREMENT_PENDING` 仅筛选尚未建单的等待申请；`status=PROCUREMENT_IN_PROGRESS` 为派生筛选，返回已关联订单的申请。返回行的原始 `status` 仍是 `PROCUREMENT_PENDING`，`status_display` 为“采购中”。
- `summary.pending_procurement` 只统计等待采购；状态选项增加“采购中”。
- 材料情况：未建单为等待采购，建单后为待到货，部分入库和全部齐备沿用已有合格入库累计结果。

## 接入边界

真实来源为 `SampleMaterialPurchaseSource`，关联缺料快照、缺料行标识及采购订单行。目前采购建单界面尚未写入此来源，不按品名或规格猜测匹配，也未添加手工改状态按钮。采购模块接入时须在建单事务内建立正确来源，之后样品查询自动显示采购中。本次没有开发样品采购建单页面，不能报告已通过该页面完成自动联动。
