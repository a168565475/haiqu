## 2. 入口与页面结构

入口不变：**生产车间 → 内部计划 → 金工计划 → 产品行“更多” → 半成品入库**。现有页面路由为 `/inventory/semi-finished/receive`，由入口带入 `schedule_product_id` 和 `plan_category=METAL`。本页处理该排产产品的金工管材，不额外增加任务、产品或采购批次选择步骤。

页面从上到下依次为：标题及“厂内金工”强标签、生产与产品上下文、入库日期和仓库/库区等填写项、15 列管材明细、备注、固定底部操作区。“未喷塑”通过只读加工状态字段及上下文文字展示。**表格后直接接备注，删除表下数量汇总条及静态规则说明块**，延续用户最新确认的精简方式。底栏保留本次入库数量，不另外堆叠重复统计区。

- 保留生产任务单、产品、订单数量、入库日期、仓库、库区、当前入库人和备注等必要信息。
- 入库人沿用当前操作员，只读；本页加工状态固定为“未喷塑”，不提供状态切换。
- 保留“入库记录”“刷新额度”“返回”“确认入库”；图稿中的“重填”仅清空未保存数量，不写业务数据。
- 提交结果不明确时保留“核对本次提交”及锁定填写状态，不能将超时视为保存失败后直接新建另一笔。
- 内部计划现有领料、查看领料记录、工价、报工和查看报工记录等操作仍保留。本次审图不删除旧业务入口，也不把旧“金工完成登记”的手工数量当成新管材完成依据。

## 3. 主表字段与数量含义

主表固定按以下顺序展示 15 列，属性分列、单行显示，不将规格、厚度和切割长度拼成一个字段。

| 序号 | 列 | 含义 |
| --- | --- | --- |
| 1 | 部位 | 当前产品 BOM 管材部位；业务按稳定部位身份关联，不按同名猜测 |
| 2 | 材质 | 当前部位对应材质 |
| 3 | 规格 | 截面、管径等规格 |
| 4 | 厚度 mm | 独立厚度字段 |
| 5 | 切割长度 mm | 独立短管长度字段 |
| 6 | 原料颜色 | 未喷塑实物颜色；不得替换成订单目标喷塑色 |
| 7 | 单耗 | 每个产品使用的支数；示例可为支/把，沿用实际产品单位 |
| 8 | 订单需求 | 产品数量 × 单耗形成的净需求，不含重新追加的备料余量 |
| 9 | 实领投入 | 已有合法领料出库凭证支持的累计投入支数，不是当前原料库存 |
| 10 | 最低报工 | 各必需工序有效累计报工的最小值；可打开依据弹窗 |
| 11 | 已入 | 该部位累计首次入库量，不因公共半成品被领走而回减 |
| 12 | 已直发 | 已加工件实际直接交接的累计支数 |
| 13 | 待发预留 | 尚未实际交接、仍有效的外发预留支数 |
| 14 | 可入 | 当前允许本次办理的剩余支数，最终由服务端复核 |
| 15 | 本次入库 | 用户输入，按整数支办理 |

当前数量规则表达为：

`可入 = max(0, min(订单净需求, 实领投入, 必需工序最低累计报工) − 已入 − 已直发 − 有效待发预留)`

同一有效工序先累计多人、多次报工，再取各必需工序的最小值。跨排产、跨领料单不能重复使用同一份完成量；同一稳定工序仅调整单价或版本时，历史有效数量仍累计。新工序不继承另一工序的数量。

本页允许按部分部位、分次将已完成管材入未喷塑公共库存；已领原料不再扣减，入库不能自动抬高报工完成量。已入半成品以后从公共库存外发，不再二次占用首次金工完成额度。

## 4. 填写与异常状态

- 不设置选择列或勾选框；有可入额度的部位可以直接填写。
- 有效正整数表示本次入库，空白和 0 跳过；全空或全 0 不能提交空单。
- 负数、小数、非数字、不安全的大整数及超过额度的值必须阻断，不能静默当作空白。厂内加工件按支办理，不套用原管材整根倍数规则。
- 数量错误沿用现有 **ERP 浮动气泡 `ElMessage`**。不另造输入旁提示交互，也不把普通数量错误重复挂在页顶长期显示。
- 有完整有效依据、最低报工确实为 0，属于“尚未报工/尚无可入量”，显示数值 0，并禁用本次入库。
- 缺有效工价方案、缺必需工序、工序或部位身份不能唯一对应、报工单位不能合法对应到支，属于“依据不完整”，应显示明确阻断原因，例如“请先完善工价方案”。不能把这些情况伪装成合法的 0 报工。
- 订单或投入额度耗尽，即使已有报工，也不能继续入库。依据弹窗需要能够解释限制来自需求、投入或占用，不能只展示最低报工减已用。
- 已批准但尚未生效的未来方案需要保留既有数量保护：若本次新增入库会使未来适用工序的有效报工不足以支持已处理及预留，必须阻断并说明原因。未来仅同工序改价不应被误判为新工序；不借未来报工增加当前额度，也不把未来工序混进当前最低报工值。
- 日期沿用既有有效性校验，页面日期选择不构成放宽报工生效范围或使用未来报工的授权。
- 已打开页面的报工、方案、BOM、领料或占用变化时，需要刷新并重新核对；刷新成功后的重新确认提示用气泡。读取失败、无权限、缺依据或提交结果不明确等阻断状态仍需清楚可见。

## 5. 两个附属弹窗

**最低报工依据弹窗**：通过主表“最低报工”进入，复用 `AppWindowDialog`。展示部位、有效工价方案及版本、批准状态、计量单位、必需工序和各工序有效累计报工，明确最低值及需求、投入、已入、已直发、预留、可入之间的关系。只有当前有效依据可以用于当前最低量；未来方案阻断单独说明，不能用一个 0 混淆“无报工”和“资料缺失”。该窗口只解释数量，不提供手工改完成量或修改工价的入口。

**提交确认弹窗**：保留当前生产产品上下文、入库仓库/库区、入库日期、正数部位及本次数量，状态固定未喷塑。提供“返回修改”和“确认入库”，确认时再次核对有效报工和共享额度。空白/0 行不计入本次入库；不制造零数量流水。设计演示必须明确没有写入业务单据或改变库存。

弹窗内必要的依据和确认说明仍保留；用户删除的是主表下方的重复汇总及静态规则块，不等于删去附属窗口的核对信息。

## 7. 现状与目标差异

| 当前真实实现 | 本稿目标及后续开发含义 |
| --- | --- |
| 金工入库必须勾选，使用原生日期、下拉及数量输入 | 无勾选、正数纳入，使用现有 ERP Element Plus 控件；车缝等其他页面不因本稿自动改动 |
| “生产订单”字段实际返回生产任务号 | 图稿明确为生产任务单号；销售订单号等需要另取真实数据，不把一个编号复用成多个含义 |
| 原界面将材质/规格组合展示 | 拆为材质、规格、厚度、切割长度、原料颜色，保留各自物品身份含义 |
| 带喷塑工艺的金工管材仍被旧服务全部排除 | 后续 D1 开发须允许满足依据的部分管材先入未喷塑公共库存；本稿不宣称已实现 |
| 现预览有需求、已入、投入支持和可入，但无完整报工及预留解释字段 | 15列和依据弹窗需扩充真实预览契约，复用 S2 数量服务；不得在前端用示例值计算业务额度 |

## 8. 风险、开发范围与验收记录

本轮只交付 D1 设计说明、图稿和截图，不修改主系统业务代码，不写库存或数据库。用户确认本页后，后续实现范围才包括金工入库界面、必要的真实预览字段、首次入库数量保护和相应入口对接。D2精简版、D3回货、D4详情、D5库存及领料不在本页自动授权范围内；不新增手工完成量、补料补做、跨部位替代或权限豁免。
