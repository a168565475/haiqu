日期：2026-09-29。范围：用户确认的 D1 主页面、最低报工依据弹窗、入库确认弹窗及其必要异常状态。开发位置为 `qa/tube_revision_s3_20260929` 隔离副本。未合入主 ERP，未修改主库。

交付确认：用户在收到本报告对应的实际截图、测试结果及隔离边界说明后回复“确认”，D1实际页面验收通过。该回复不扩大为主ERP启用或其余页面开发批准。下一步核对记录见 `tube_revision_d1_acceptance_and_next_20260929.md`。

## 1. 确认与对应要求

本轮用户“确认”批准上一轮 D1 图稿。冻结证据为 `qa/tube_revision_d1_20260929/approved_design.json`；原设计 manifest 保留当时的待审核记录，不改写历史。最终复核 9 个设计文件和 15 张设计截图内容未变。

| 已确认要求 | 本次实现 | 为什么这样改 |
| --- | --- | --- |
| 厂内加工后可以部分入库，不必所有部位完成 | 正整数行办理，空白/0跳过；部分部位、部分数量可提交 | 仓库根据实际收到的加工件办理 |
| 加工完成以该部位必需工序最低累计报工为准 | 展示订单需求、实领投入、最低报工、已入库、已直发、待发预留、可入库；最低报工可点开查看工序与方案依据 | 防止把某一道工序的较大数量误认为整个部位已加工完成 |
| 有喷塑计划，也允许先收未喷塑件 | 金工入库固定“未喷塑”，匹配并显示实际原料颜色 | 入库实物尚未喷塑，不提前使用订单喷塑色 |
| 入库与直接外发不能重复占加工数量 | 同一任务产品、稳定 BOM 部位共用额度，待发预留也扣可入量 | 防止从不同排产或入口重复使用同一批加工产出 |
| 公共库存，不指定采购批次 | 正常增加公共未喷塑半成品库存，保留真实来源流水 | 同类实物可以统一摆放、领用 |
| 原料领料时已扣库 | 本次只增加半成品，不再扣原料，不抬高旧手工完成数 | 避免重复扣料或凭入库反向制造加工额度 |
| 气泡校验，不要表下额外汇总说明 | 非法数量用 ERP 气泡；表格直接接备注；底部保留提交总数 | 遵循已确认交互与精简布局 |
| 日期、下拉等沿用 ERP | 使用现有日期/下拉和通用窗口；44px表头、40px行、32px控件，主题色聚焦 | 不新增一套不一致的控件 |

当前可入量按需求、有效投入、当前必需工序最低报工三者较小值，扣累计首次入库、实际直发及有效待发预留，再核对已批准未来生效方案能否承接已有与新增数量。缺依据和有效工序尚未报工的 0 分开处理，不能靠旧人工完成量绕过。

以下均位于隔离副本 `qa/tube_revision_s3_20260929`：
