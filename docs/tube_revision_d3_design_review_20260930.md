# D3整单喷塑入库设计审阅

日期：2026-09-30。状态：图稿和浏览器核对已完成，待用户确认本页设计；尚未获得本页业务开发批准。用户已验收D4实际开发结果；本次只制作D3图稿，不开发D3业务接口、模型、库存写入或主ERP启用。

## 依据与要解决的问题

用户已确认：一张新管材外发单一个任务产品、一个来源；每个部位一个加工厂，不同部位可以不同厂。整单按原单数量一次发出；回货只登记一次，允许少回，0或空白表示本部位没有回货。每个少回部位必填差额原因，所有行全0也可结束，不产生0数量库存流水。取消、退回、返工、结清、后续补登记不属于新管材回货。

现有S3只完成D1金工未喷塑入库、D2新建待发预留及D4实际发出／待发取消。D4的喷塑入库按钮尚禁用，新回货凭证与结束状态尚不存在。旧回货按厂分批，不能直接复用该写接口实现整单一次处理。

## 页面和入口范围

1. 外发单详情的喷塑入库入口带入原单，进入D3收货页。
2. 半成品库存入口先选择待回货新管材单，再进入同一D3页。选单窗口只演示新单候选：加工中、有真实实际发出凭证、无最终回货结果。生产任务、产品、来源、部位、厂家及颜色带自原单，不重新选择批次或实际颜色。
3. D3主页面逐部位填写实收、差额原因和入库库区；最终复核窗显示全单所有行，包括0行和不同加工厂。
4. 已办理的D3结果只读。D4的已结束详情、统一外发列表、统一入库记录及库存领用页面按后续逐页范围处理，不能因此宣称这些页面已接入。

本轮图稿包括收货主页面、仓库选单窗口、整单最终复核窗口与D3已结束只读结果及必要异常状态。不改现有半成品库存整页或正式外发列表布局。

## 交互与业务细节，图稿确认时须一并检查

- 实发数量只读，实收只允许0至原单实发之间的整数。空白按0参与全单结算，不能像普通金工入库那样直接跳过空行；负数、小数、文字及超量用ERP气泡提示并保留原输入。
- 每行差额＝实发－实收。少回行差额原因必填，全回行无需原因。0／空白行同样必须记录差额原因。
- 沿旧D3的存放布局：一个目标材料仓，每个正数实收部位选择该仓下库区，可选择不同区；0／空白行不产生入库，库区禁用且无需填写。没有实收的整单不强制选择仓库／库区，仍需日期及逐行原因。这项免选位置行为在本页图稿审批时明确。
- 更换目标仓库会重置各行库区，先提示确认；保留已填写实收和差额原因，不无声清空数量。
- 收货日期默认当天2026-09-30，经办人采用当前操作人只读，入库备注选填；不新增计划日期之外的收货日期业务限制。
- 喷塑颜色只读，使用原单冻结颜色及实物属性；不选择采购批次、回货批次，不重新换算根或米。仅正数行新增已喷塑公共半成品库存。
- 原材料按整根发出的切割余量，回货上限仍按原单实发支数，不能再用订单净需求直接截断合法原单回货。后续装配领用上限仍按对应订单部位需求控制，两者不能混用。
- 确认窗口明确本单全部部位、全部厂家一次结束，后续不追加回货或修改结果。实收正数时按钮为“确认入库并结束”；全0时为“确认结束”，明确库存新增0，不叫取消或结清。
- 少回不返还原材料或未喷塑库存，也不释放已经发生的外发与金工首次产出占用。用户继续金工计划是后续业务，本页不新增补做、报废、不良品、退货或重加工路径。
- 提交未知时锁定已提交内容，只核对原请求；已结束、待发、取消、空明细、无权限及读取失败均不能再次办理。

## 修改前后与开发影响

旧稿允许同部位多厂、要求0行显式填0、表下有汇总规则块，且存在按厂回货的历史业务。新稿采用当前单部位单厂规则，空白按0，全单所有行复核一次，汇总移至固定底栏，减少占用主表空间；逐行库区保留旧稿，不擅自压成唯一库区。

图稿批准后的实现需要新增最终回货单及全部行凭证、结束状态、唯一回货和请求约束、候选／预览／整单确认／原请求回查接口，沿用现有回货权限、工艺范围、Session、CSRF、ETag、事务与幂等。仅有前端图稿不能证明这些已实现。

当前已有额度与报工保护多处仅统计加工中单。增加结束状态时，必须继续统计其实际发出量，防止结束后重新释放可发／可入或报工改删额度。公共未喷塑喷塑回库是阶段转换，不能再次计作厂内首次产出。该部分必须纳入后续隔离后端及并发回归，不改变面料规则。
