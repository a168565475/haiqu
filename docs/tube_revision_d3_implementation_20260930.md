## 本步改什么，为什么改

1. 按已确认D3图稿接真实已发出的新管材原单，三个材料来源共用收货页；仓库选单与原单喷塑按钮进入同一业务。
2. 回货按原单全部部位及加工厂一次登记；每行实收0至实发之间的整数，空白按0，所有少回行必填差额原因。全0保留全部行，只结束原单，不产生库存流水。
3. 正数行按各自库区增加冻结属性、颜色对应的已喷塑公共库存；不重复扣原料、未喷塑库存，不重新换根米，不关联采购批次。
4. 新增最终回货凭证、全行明细及唯一请求约束，并增加已结束状态。结束后保留实际发出额度、金工首次产出与报工保护，防止从其他入口重复使用同一已加工数量。
5. 整单事务、权限、CSRF、单据版本、唯一请求和结果回查共同防止重复入库。提交结果未知锁定原内容，只核对原请求。
6. 1920×1080按冻结图稿验证表头44px、行40px、控件32px、左右内边距10px、主题色、单层边框及内部滚动，开发后提供实际业务截图。
