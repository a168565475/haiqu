# D4统一外发列表：接入新管材单的待确认设计

日期：2026-09-30。当前阶段仅设计，尚未接入业务。上一页D4已结束详情和只读凭证已获确认；这份图稿需要单独确认后才能开发。

## 1. 修改原因及现状证据

现有统一外发列表只合并旧普通外发和旧重加工单，尚未合并新管材单。此次在隔离环境以现有授权用户只读读取：列表返回0条，同时三个新管材已结束单的最终凭证分别存在原材料20/20、未喷塑半成品20/18、未入库半成品20/0（发出/实收，单位支）。因此本页需要接入新渠道及正确详情入口，不能只改显示名称。

现状截图和读取结果：`qa/tube_revision_d4_list_design_20260930/current-unified-list-1920.png`、`current-evidence.json`。这只是隔离测试库、当次用户授权范围的读取结果，不代表主ERP总单数或库存。

## 3. 设计规范及布局细节

- 唯一验收尺寸1920×1080；沿用HiTree导航、ERP字体、暖色背景、按钮和状态标签。
- 表头44px、行高40px、控件32px、单元格左右10px、圆角5px；主题色`#c84e28`，输入和下拉聚焦使用该色。
- 下拉直接复用ERP的Element Plus控件、中文配置和主题；本页日期仅为预计日期列，没有新增日期输入。后续涉及日期输入继续沿用计划排产。
- 共15列：外发单号、生产任务单、产品名称、品号、货号、订单颜色、材料来源、加工工艺、加工厂、发出数量、回货数量、管材差额、预计回货日、状态、操作。
- 基础列宽合计1600px，产品名称最小155px并自动补足剩余宽；1920实测该列215px、表格内部1660px，右边不留空带。数字右对齐，其他信息左对齐，单行省略并可悬浮查看。
- 工厂多家仍占一格，显示首家加家数，悬浮查看全名；一单仍只有一行，不拆成可独立回货的分厂行。
- 新管材一单一个产品；旧多产品原单显示“等N款”，品号、货号、颜色显示“多款”，不能把第一款信息当成整单。
- 管材一个外发单可能含多种部位、材质、规格和厚度。本页为整单列表，不把某一部位规格当作整单规格；这些属性继续在已确认明细页分列展示。
- 外框只有一层1px；组件边缘补线关闭，内部网格独立。没有勾选列、底部规则说明块或出入库操作面板。
- 原有“新建外发单”“待外发材料”“加工厂管理”入口保留，不在本页擅自删除旧写流程；具体管材旧入口停用/旧专用代码清理继续按S7/S8审批范围办理。

## 4. 数量、状态和筛选的实现约束

### 数量与状态

- 新管材只有实际发出凭证才显示实发支数，待发和待发取消显示“未发出”，不以计划数替代实发数。
- 新管材有最终凭证且实收0，显示“0 支、已结束”；尚未办理回货显示“未回货”；已结束而凭证无法核对显示“—”，不能假填0。
- “管材差额”只在新管材有最终凭证时显示实发减实收的支数；不是待回货任务、不恢复额度，也不新增结清/补登记入口。
- 旧回货仍为原合格回货口径。“回货数量”表头悬浮说明两种契约，不能改称所有旧单的全部实收入库。
- 面料保留“183.75米发出/120套回货”等原单位，差额显示“—”，米和套不得相减。旧多单位数据同单位合计、不同单位并列；保留原4位小数精度，不跨单位合计。
- 旧状态仍保留待交接、部分回货、已结清等；旧已完成与新管材已结束在同一状态筛选中识别，行内按各自标签显示，不把少回新单标为部分回货或已结清。
- 旧已发料撤销仍保留历史实发凭证数量，不能因`CANCELLED`将其覆盖为未发出。旧更多菜单仍按原权限、查看渠道、直发条件和后端操作标志显示，不能仅由待外发状态推出可删除。
- 旧重加工没有产品摘要或预计日期，显示“—”；旧金工受限摘要中无权取得的任务、产品、工艺、日期也显示“—”，不通过新列表补查受限资料。

### 来源映射

图稿的筛选值只是设计适配值，开发不得原样传给旧接口。新旧内部同名`METAL`不同含义，必须按渠道独立判断。

| 设计中来源 | 新管材 | 旧流程 |
| --- | --- | --- |
| 原材料 | `TUBE + RAW_PIPE` | `ORIGINAL + RAW` |
| 未喷塑半成品 | `TUBE + PUBLIC_SEMI` | 无 |
| 未入库半成品 | `TUBE + METAL` | 无 |
| 金工加工件（旧流程） | 无 | `ORIGINAL + METAL` |
| 重加工件（旧流程） | 无 | `REWORK` |
| 待选择（旧流程） | 无 | `ORIGINAL + UNSELECTED` |

筛选只作用于各自已授权记录，不合并权限。加工厂筛选先投影该厂明细再计算数量和差额；状态仍为整单，点击查看仍打开整单，一单一次登记规则不变。多厂单示例：整单8000/6900/1100支；选海丰后4000/3960/40支；另一厂4000/2940/1060支。

### 查询与异常

实现时采用新管材独立摘要，按`TUBE:{id}`与两种旧渠道隔离行标识；先合并候选及分页，再批量读取当页摘要。不得每行调用详情/采购批次/动态BOM/最低报工来源查询，也不得使用会额外核算动态额度的完整订单序列化。

授权边界、旧数量投影、原筛选和请求竞态保护沿用；历史工艺/加工厂摘要不能因当前档案停用而被抹掉。记录缺字段、加载、失败、无权限均不可显示虚构0；成功查询无匹配才显示0条。筛选选项读取失败、刷新重试、最后一页减少条数等未新增布局的状态继续沿用现有页面处理方式。
