# D5-B 半成品入库记录开发结果

日期：2026-09-30

## 开发前确认

- 已确认 D5-B 设计稿后开发。
- 本步范围是半成品入库记录列表和来源详情，不增加采购批次、退回、补登记、结清或后续处理按钮。
- 用户确认的材料来源显示为：原材料、未喷塑半成品、未入库半成品。

## 本步改动

1. 半成品入库记录接口纳入 `TUBE_OUTSOURCING_RETURN` 管材外发回货流水，列表来源显示为“外发入库”。
2. 管材回货列表的入库单号和入库日期使用实际回货单号、回货日期；搜索支持回货单号和原外发单号。
3. 外发来源详情弹窗增加管材专属信息：原外发单、回货单号、材料来源、加工厂、原料颜色、喷塑颜色、实发支数、实收支数、少回支数和少回原因。
4. 0 支回货仍保留一次性回货凭证，但不生成库存流水，因此不在入库记录列表显示零数量行。
5. 记录列表继续沿用现有 ERP 表格和来源详情弹窗；未引入采购批次或批次关联查询。

## 验证结果

- 后端管材回货记录详情测试通过：确认正数回货显示外发来源、回货日期和实发/实收/少回字段。
- 后端 0 支回货测试通过：无半成品入库流水记录。
- 原有管材回货接口测试 31 项通过。
- 前端 `npm run type-check` 通过。
- 前端 `npx vitest run src/api/internalReceipts.spec.ts`：5 项通过。
- 前端 `npm run build` 通过，仅保留既有大资源分包提示。
- 浏览器 1920×1080 只读验收通过：页面、列表和来源详情弹窗无页面错误、无控制台错误、无写请求；表头 44px，数据行 40px，控件 32px。
