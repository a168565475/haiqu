# D5-C 公共半成品领料实施结果

日期：2026-10-01

## 确认依据

本阶段使用已确认的 D5-C 设计图 `qa/tube_revision_d5_design_20260930/d5-c-semi-issue.png`。沿用 ERP 规范：1920×1080 主验收尺寸、表头 44px、数据行 40px、控件 32px、暖色背景、`#C96442` 主题色、搜索和下拉沿用现有计划排产控件。

## 已实施内容

### 半成品领料窗口

- 半成品主表增加材质、加工状态和可用说明，规格列保留管材规格/切割长度。
- 半成品选择弹窗增加搜索、加工状态下拉筛选和查询按钮。
- 半成品候选表改为按行“添加”，不再使用多选框；候选列为部位、材质、规格、颜色、加工状态、公共可用、匹配依据、操作。
- 候选只显示公共可用量大于 0 的半成品；已选择内容仍在主表保留。
- 半成品数量继续按正整数支/套校验，原材料管材的整根换算和原材料多选流程保持不变。

### 公共额度与库存规则

- 删除“有喷塑计划就过滤金工行”的旧逻辑，已喷塑、未喷塑可以同时成为候选。
- 以 `component_identity + unit` 聚合同一 BOM 部位的需求、已领取、当前及其他领料单待审核占用；提交和确认都拦截合计超出订单部位需求。
- 同步一个工艺时，会同步该部位同单位的全部工艺需求，避免未选工艺继续保留旧需求或遗漏历史已领数量。
- 来源仍按公共库存实物属性匹配，不关联采购批次，不再次扣除原材料根数和米数。
- 确认出库后的审计快照重新读取共享额度，记录实际扣减后的已领和剩余。
- 管材厂内半成品身份解析在一次需求构造中复用原料解析缓存，避免多部位重复查询原料档案。
