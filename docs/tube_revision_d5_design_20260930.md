# D5 公共半成品库存、入库记录与领料设计稿

日期：2026-09-30

## 当前检查结果

- `stock_kind=SEMI` 后端接口已经能返回公共半成品，但材料库存页面没有从路由查询参数初始化半成品状态，直接打开半成品入口仍显示原材料。
- 新管材喷塑回货使用 `TUBE_OUTSOURCING_RETURN` 流水来源，当前半成品入库记录接口未纳入该来源，因此外发回货成功后不会出现在入库记录列表。
- 当前公共半成品领料已经按支数和属性匹配，但页面需要把“已喷塑／未喷塑”和 BOM 属性匹配讲清楚，不关联采购批次。

## 本次设计范围

1. 半成品库存页：接通 `stock_kind=SEMI`，增加加工状态列；不显示顶部统计卡片，直接突出筛选和库存明细；保留品类、类型、材质、规格、颜色、厚度、部位、仓库、库区和数量。增加“喷塑入库”入口，不增加半成品档案。
2. 半成品入库记录页：外发回货和厂内入库统一列表，外发回货显示“外发入库／已喷塑／支”；来源详情继续用弹窗，不在表格右侧常驻展开。0 回货不生成零数量记录。
3. 生产领料半成品选择：按 BOM 部位、品类、材质、规格、颜色、厚度和加工状态匹配；允许已喷塑与未喷塑混领，但合计不超过该订单该部位需求；不显示采购批次。

## 设计规范

沿用现有 ERP 页面：1920×1080 主验收尺寸，表头 44px、数据行 40px、控件 32px、5px 圆角、暖色背景和 `#C96442` 主题色。日期和下拉使用现有计划排产控件，输入聚焦使用主题色。列表属性保持单行独立列，来源详情使用通用弹窗。
