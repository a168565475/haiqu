# 管材设计第二轮修改与逐页确认清单

状态：根据2026-09-29最新答复修订设计规则。本轮只修订D2图稿及方案，不进入S3业务开发。D1的规则复述不等于该页已获开发批准；D3整单全0结束例外待确认，本轮暂不制作或开发D3。

## 最新要求优先于旧整套图审批

1. 相似填数页面沿用D1交互：不设勾选，通过填写正数决定本次办理项，空白或0跳过，全空或全0不能提交空单。负数、非数字、超量或超出本页单位精度的数量用ERP气泡提示并阻断，不能当作未填写静默略过。管材按整数支，面料米数等继续保留各自原有单位和精度，不把通用交互规则解释为所有物料一律整数。喷塑空白/0行的整单结算含义及全0例外见下一节。
2. 新建管材外发单每个BOM管材部位只选一家加工厂，同一部位禁止拆给多家；同单不同部位可以选不同加工厂。“取消分厂”指取消同部位拆厂的数量分配控件，不是整单只能一家厂。旧多厂单历史记录仍保留。
3. 原材料外发支数、每根切割支数、原材料长度、扣除根数、扣除米数放在同一表格。申请支数除以BOM每根切割支数必须整除，不自动向上取整。例如每根6支，600支=100根；601支拦截。原材料长度3.95米时，扣100根、395.00米。保留原有订单额度及库存校验。
4. 一张管材外发单只对应一个任务产品，可含该产品多个BOM管材部位。原材料和公共未喷塑半成品外发先选择生产任务单，再选该任务的一个产品，再匹配对应BOM管材。厂内已加工件从内部计划带入对应产品。公共库存不因此绑定采购或回货批次。
5. 每个页面单独出图，分别说明沿用规范、交互细节和业务改变，由用户确认该页后才开发。不得沿用旧整套批准自动跳过，也不得把用户复述页面规则写成批准该页开发。页面附属弹窗和重要输入状态须一起交付。表头44px、数据行40px、单行控件32px；未单独设计的控件沿用当前ERP。

## 最新答复与唯一待确认例外

- 加工厂范围已明确：每个BOM管材部位一家厂，同单不同部位可不同厂，不再保留“整单一家厂”的建议。
- 产品范围已明确：一张管材外发单一个任务产品。
- 喷塑未回的部位可以填0或留空；空白按0参与本次整单结算，保留本行发出量、0实收、差额和必填差额原因，不将该行留作下次回货。只有正数实收产生库存流水。
- **待确认例外：整单所有实收为0或空白时能否结束。** 历史整体方案已批准“整单全0可结束且不新增库存”，最新相似填数页又要求“全空或全0不可提交”，两者在喷塑整单结算上有冲突。未获得针对该例外的答复前，保留历史已批准全0结束规则，不自行撤销，也不写成该例外已再次确认；D3图稿和开发暂缓。本轮仅继续D2。

## 已有工作的影响

S2已完成的报工数量、共享额度和并发保护基础不因本次视觉修订而撤销。正式S3管材入库/新建外发只办理合法正整数数量行，同时后端继续校验，不能凭前端跳过非法项。喷塑整单结算须保留0和空白行的结果，不能套用“只提交正数行”而漏结整单。其他相关页面仅逐页套用填数交互，不改变面料米等单位精度。本轮只改D2隔离图稿及方案，未接业务API，未修改实际库存；本次文档子任务仅改三份方案文档。

S3接入须保留既有来源边界：任务→单产品是前端选择顺序，仍须唯一关联现有有效排产产品；无有效计划或无喷塑工艺时提示不能办理。来源摘要优先扩展外发`source-plans`及其权限，不使用新建排产的`task-candidates`，也不要求操作员额外取得整个生产任务读取权。部位以稳定BOM部位ID保证唯一，不能按名称或重复明细绕过单部位单厂；厂内加工件和公共未喷塑半成品按整数支，不套用原管材整根限制。具体实施边界见总方案第六节。

旧approval.json和manifest.json仅作第一版历史证据；第二版使用approval-v2.json、当前D2改稿使用approval-v3.json逐页记录，旧批准不覆盖本轮改稿。原D1和画廊修改前副本位于qa/tube_revision_design_v2_20260929/before。
