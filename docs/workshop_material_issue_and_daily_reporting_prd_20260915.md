# 厂内车间领料与每日报工方案 V0.5

日期：2026-09-15。状态：方案讨论稿，已纳入报工三项确认及最新“按生产订单开领料单、禁止超领、仓库审核扣库存”要求；其他建议不视为已确认规则。本文未执行数据库变更、业务开发或真实库存操作。

## 1. 目标与本轮确认

在已有主排产与委外回货业务基础上，补齐：车间查看生产任务 → 申请领料 → 仓库发料 → 车间开工 → 负责人录入员工每日产量 → 查看工序进度与计件工费。

此前主排产只做“能排产、能看排产”，本轮是在该基础上新增生产执行方案，不改变“一张任务单一张有效主排产计划、不做分批排产”的规则。领料批次和每天报工记录不等于新增排产计划。

本轮先完善业务方案，之后按确认结果设计页面、原型、数据库与开发计划。计件工费统计在范围内；考勤、加班、社保、工资发放、完整成本核算不自动纳入。

## 2. 当前系统核对与必须补充的基础资料

本节依据当前源码和已有设计文档，未核验真实数据库库存、部署状态或线上接口。

| 当前事实 | 对本方案的影响 |
| --- | --- |
| 当前代码已有主排产、排产产品和所选工艺模型 | 车间任务应关联排产产品及厂内工艺，不再另选销售订单产生独立数量 |
| 已有车间、车间员工、工艺、工序资料 | 复用真实资料，不再平行创建同名员工和工序 |
| 工序目前以产品名称文本关联，缺少报工单位和标准工价字段 | 需补稳定产品关联、工序单位和工价维护；不能仅按同名产品自动匹配 |
| 车间员工与系统登录员工是不同对象 | 产量归属车间员工；录入、修改、确认留存登录操作者，两者不能混用 |
| 当前固定车间包含金工、车缝、装配、敲布孔，没有独立裁剪车间 | 裁剪属于哪个实际车间按工艺关联核实，不能把四个计划分类直接当四个部门 |
| 已有生产批次汇总与样品生产逻辑，但不是员工工序报工 | 不把每道工序产量直接写入整单成品产量，也不直接套用样品流程 |
| 委外与半成品已有设计；本次未核实其真实库存服务已落地 | 方案接受用户“半成品已回来”的业务前提，开发前核验库存接口与来源明细 |

建议最小补充三类基础资料：

1. **产品工序清单**：产品、厂内工艺、工序、加工对象、报工单位、每个产品需要完成的工序数量，以及必要的前后关系。已有工序资料不等于已经定义好每个产品的执行顺序和数量换算。
2. **标准工价**：产品、工序、计价单位、单价、生效日期、启用状态、修改记录。计价单位与工序报工单位一致。
3. **订单材料需求清单**：按生产订单产品及对应 BOM 确定材料需求和单位换算，同一订单多个产品的相同材料可汇总展示，保留产品/BOM 来源分配。车间、工艺用于说明领用用途，不分别复制整单领料额度。需求计算规则见第 4 节。

若同一产品同一工序对不同部件实际执行不同工价，应确认是否拆成不同工序；当前已确认的工价键仍为“产品＋工序”，不擅自增加按员工定价。

## 3. 车间生产任务

建议一条车间任务对应“排产产品＋一项厂内工艺”，下面展示该产品在该工艺下需要执行的工序。员工报工绑定具体工序；有多个加工部件时同时绑定部件。

进入金工、裁剪、车缝、装配计划，可以查看相应车间任务并办理领料、开工、报工。领料入口自动带入所属生产订单，实际领料单及材料额度以生产订单为依据；排产、产品、工艺和车间是用途关联，不能各开一份独立订单额度。四个计划沿用主计划来源，不分别维护第二套排产数量。一个工艺下多道工序不增加主排产数量。

任务列表建议展示：排产单号、生产任务单号、订单号、产品图片/编号/名称/规格/颜色、工艺、所属车间、排产数量及单位、计划日期、领料情况、生产状态、工序完成概况、操作入口。

计划日期继续沿用：金工显示金工回货时间；裁剪与车缝显示车缝回货时间；装配显示成品入库时间。

建议分开显示两种状态，避免把“领了一部分料”和“生产了一部分”混成一个状态：

| 状态维度 | 建议状态 | 判定依据 |
| --- | --- | --- |
| 领料状态 | 未领料、部分领料、已领齐 | 按生产订单材料需求与累计审核通过领料计算；车间展示其用途分配，不能把整单已领齐等同于本车间已收到 |
| 生产状态 | 待开工、生产中、待完工确认、已完工 | 开工记录、必需工序的有效完成数及负责人确认 |

“已领齐”只表示满足用料目标，不表示已经完成生产。必需工序与换算关系未配置时，不能自动判断整个产品已完工。

## 4. 领料与开工

### 4.1 领料单流程

已确认：按生产订单领料，采用领料单，记录本次领什么、领多少、谁领、什么时间，仓库审核确认后扣库存。本期不做超领。

本文“生产订单”沿用当前系统生产任务单对象，界面最终名称保持项目统一；不另建一个同义订单对象。它与上游销售订单、主排产单分别关联。建议一张领料单对应一张生产订单、一次领取，可含多种材料；同一生产订单可有多张领料单。

1. 选择生产订单，再从该生产订单内选择产品；从车间任务进入时可自动带入来源。基本信息不显示销售订单选择或只读框，保留产品选择器及所选产品图片/编号/名称/颜色/订单数量。按所选产品定位 BOM 分区及委外回库半成品；产品切换不能重置订单材料累计已领额度。
2. 勾选本次要领的材料，逐项展示“本单需要、累计已领、还能领取、当前可发库存”，填写本次领取数量。
3. 填写领料人、领料时间、领取车间/用途、备注，保存或提交领料单。制单人与实际领料人分别记录。
4. 仓库审核订单、需求余额、领料数量和公共可用库存，不选择采购单、入库批次或出库来源。
5. 仓库确认时，在同一笔操作中写入审核结果、出库明细、订单累计领用和库存流水，扣减对应物料的公共库存一次。
6. 领料单显示已出库数量、领料人、实际领料时间、审核人、审核确认时间，并可返回生产订单查看累计领用。

建议本期单张领料单整单审核确认，不在一张单内再做多次出库；需要分次领取时另开领料单。审核发现数量不符时退回修改，不默默覆盖原申请。此处单张单据处理方式是实施建议，未扩展成已确认的分批审核功能。

### 4.2 单头与材料明细

**分类领取（2026-09-16 已确认）：**选择生产订单后，按该订单 BOM 分区组织原材料：管材类、五金件、塑料件类、辅料类、面料类、包材类；另设“委外回库半成品”分类。保留本次领料单跨分类已选择的明细和数量，切换分类不清空本单内容，也不重置订单累计额度。

不展示 BOM“裁剪明细/裁片明细”作为可领料分区或数据表，也不能把 BOM 中列有裁片视为存在库存。委外回库半成品显示名称、独立颜色列、已完成工艺、单位、需求、已领、剩余可领、合格库存及本次领取，不显示图片或所属产品列，不复制裁片尺寸、排版和裁剪用量表，也不要求选择回货批次。此前按任务产品和 BOM 部件识别半成品的规则仍用于防止错领；最新公共库存要求是否进一步允许不同生产订单的半成品互领，尚未单独明确，本页不新增跨订单半成品选择功能。

不显示 BOM 裁片明细不等于禁止领取“已完成裁剪”的委外半成品；凡符合该订单需求且已回货合格入库的半成品，均按已完成工艺标识。原材料分区与半成品库存是不同来源，不能用 `FABRIC` 大类一次取出面料、辅料和裁剪明细。

| 单头字段 | 说明 |
| --- | --- |
| 领料单号、生产订单 | 系统编号、必填来源；页面不显示销售订单，后台已有上游追溯关联不删除 |
| 选择产品 | 仅选择本生产订单内的产品，带入对应 BOM 分区与合格回库半成品；未选订单时不提供全局产品候选 |
| 领料人、领料时间 | 实际领取人员与业务发生时间；提交阶段尚未领取时可先填预计时间，仓库确认需核实实际时间 |
| 领取车间、用途 | 建议记录，可关联排产产品与工艺；不以此另建领料上限 |
| 制单人、制单时间 | 自动记录，与领料人分别保存 |
| 状态、审核人、审核时间 | 审核操作留痕；审核时间由系统记录 |
| 备注 | 补充领取说明 |

| 材料明细字段 | 定义 |
| --- | --- |
| 材料编号、名称、规格、颜色、单位 | 以真实材料标识关联，不能只按名称合并；表格不显示图片，颜色独立列 |
| 本单需要数量 | 该生产订单对该材料的已确定总需求，来源可展开到产品和 BOM |
| 累计已领数量 | 仓库已审核确认发出的数量；草稿、待审核、已退回不计入 |
| 还能领取数量 | 本单需要数量减去已确认占用该需求的累计数量，不是仓库总库存 |
| 其他待审核数量 | 建议单独提示，帮助识别重复申请；不伪装成已经发料 |
| 当前可发库存 | 同种材料跨采购归属订单共用的合格可用余额，按实际品质和库区筛选；不限定本订单采购来源 |
| 本次领取数量 | 用户填写，本期必须大于零且不超过订单剩余额度及实际可发库存 |
| 本次确认后剩余可领 | 还能领取数量减本次确认数量 |
| 公共库存扣减 | 审核确认后扣对应物料可用余额并记录订单领用流水，不进行采购批次来源分配 |

原材料按米、千克、根等真实库存单位领取；委外半成品沿用已确认的套数单位，按原料和半成品分区展示。领取半成品不再次扣除制造它曾用过的原材料。工序报工的根、片等单位仍需独立换算。

### 4.3 需求与不超领规则

建议以生产订单对应的已确定 BOM 材料需求作为本单需要数量：BOM 若记录单位用量，乘订单产品数量；若已经是整单需求，不再乘一次。最终需核对现有 BOM 每个数量字段的实际语义。采购多少、库存多少、某次排产多少，都不能代替本单材料需求或自动放大领料额度。

同一订单多个产品使用同一材料，可按“材料唯一标识＋规格/颜色属性＋一致单位”汇总，保留产品/BOM 用量分配。换算不明确的不同单位不能合并。多个车间、多个领料人、多张单共同累计，不允许拆单、换车间或重新排产重置已领数量。

数量关系：

- 订单剩余可领＝订单材料需求－累计厂内已确认领料数量－累计委外已确认发料数量。
- 本次可确认上限＝订单剩余可领与对应物料公共可用库存两者的较小值。
- 本次确认后剩余可领＝确认前订单剩余可领－本次确认数量。

已确认 Q11–Q12：内部领料和委外发料既共用物理库存余额，也共用该生产订单的材料需求额度。累计已领可展开为“厂内领料”和“委外发料”，两者只统计仓库已确认的实际发出量。委外单保存、待审核领料单不算已发；委外回货不恢复已经发出的原材料额度，后续领取其半成品也不重复扣原材料。

委外既有加工套数额度与本次明确的材料需求额度是两个口径：外发加工对象仍按已确认套数规则控制；实际发出的原材料新增按订单材料需求检查。本节是对前期委外方案材料出库门禁的补充，不能因旧方案仅校验库存就漏掉本订单材料上限。

示例（无委外及其他占用）：订单需要面料 500 米，已审核领用 200 米，还能领取 300 米；本次领取 120 米，审核后累计已领 320 米，还能领取 180 米。若对应物料公共可用库存仅 80 米，本次最多确认 80 米，必须把申请数量修正后再审核。

建议提交只形成待审核单据，本期不自动预占物理库存或订单额度；展示其他待审核申请量。仓库确认必须重新锁定并校验需求余额和库存：两张各申请 200 米的单据面对剩余 300 米时，第一张确认后第二张不能原量通过，需修改或退回。后续若需要提交即预留，应另行明确规则，不能隐藏改变“还能领取”的含义。

### 4.4 状态、审核和异常

领料剩余状态的六张配套静态设计已补齐，包含公共库存审核、退回原因弹窗、已退回详情、修改重提、库存不足、超过订单额度；见[设计审阅清单](../outputs/material_issue_design_20260916/remaining_states_r1/设计审阅清单.md)。本轮六张状态设计图已获用户确认，作为后续原型依据；不代表原型、业务实现或视觉验收完成。取消出库来源后的新版待审图为该清单S01，旧LL03来源区不得复用。

建议状态为“草稿 → 待仓库审核 → 已出库”，不通过时为“已退回”。仓库审核通过与扣库存是同一个确认动作，不增加审核通过后还需再次点击扣库存的中间状态。

- 草稿、待审核、退回不扣库存。退回写明原因，修改后可重新提交。
- 确认检查材料属于该订单需求，物料身份、颜色规格、数量、单位、可用状态均匹配，并校验订单额度和公共库存余额。
- 缺需求、缺单位换算、物料身份不明、数量超过剩余可领或库存不足均不能确认；不能自行填写一个更大需求量来绕过上限。不以缺少采购批次来源分配阻止领料。
- 不开放“超领确认”、临时容差或按负责人身份绕过额度。订单/BOM 修改不得使需求低于已领数量或覆盖历史需求版本。
- 整单任一明细失败不扣其他明细库存；并发审核、重复点击和网络重试只形成一次有效出库。
- 已出库单不直接修改数量、换订单或删除。退料、撤销、冲销需独立确认业务规则；本期未定义的动作不自动恢复库存或领料额度。

### 4.5 材料公共库存、订单采购与领用查询

已确认要回答三件事：这种材料现在有多少；分别为哪些订单采购了多少；分别被哪些订单领用了多少。

建议材料库存列表按材料展示“当前库存、合格可用量”，展开两类明细：

| 查看方向 | 主要字段 |
| --- | --- |
| 订单采购记录 | 采购归属生产订单、采购单号/明细、采购数量、实际入库数量；只说明为该订单采购多少，不代表该订单专属库存 |
| 订单领用记录 | 实际领用生产订单、领料单号、车间、领料人、实际领料时间、已确认领用量、审核人/时间；不关联具体采购入库批次 |

采购数量取采购明细本身；采购单分多批入库时，不能把每一批的“采购数量快照”相加，导致采购数量翻倍。采购量不等于已到货库存，未到货不能领；不良隔离量与可用量分别展示。

采购记录和领用记录分别展示，不通过出库来源分配建立逐笔对应关系。入库增加公共库存，审核领料减少公共库存并增加实际领用订单的累计领料。直接入库没有采购订单时，采购归属显示未关联，不编造记录。

**入库后公共使用，采购归属订单与实际领用订单分别统计。** 库存按真实材料身份、颜色规格、单位和可用状态共用，不因采购归属其他订单而禁止领取；领用额度只检查实际领用生产订单。不能仅按相同名称合并不同物料，也不能将不同单位或不合格库存混入可用余额。

例：某面料公共可用库存600米，A订单审核领用120米后库存为480米，A订单已领增加120米。此前为B订单采购的数量与B订单自身累计领用不因此改变。不生成“B采购批次发给A”的对应关系。

此规则意味着某订单虽然采购过材料，材料仍可能被其他订单先领走，不能承诺“本订单采购过就必然有库存可领”。审核页同时展示订单剩余额度与公共可用库存；取消具体出库来源的选择与展示，不引入先进先出或订单专料预留规则。

展示的“订单用了多少”本期准确含义是“已审核领用数量”。仓库发出后材料可能仍在车间，不能标成已经实际消耗；报工不重复扣仓库库存。实际耗用、余料、报废及车间转交另留记录，未确认的耗料算法不能把 BOM 理论需求当实耗。

### 4.6 与开工的衔接

已确认发料可作为车间实际投入来源，需保留订单产品与领用用途分配。委外半成品只允许领取本任务产品、对应部件、已完成工艺的合格可用数量，不良库存不能自动转可用。

建议本次投入配齐即可开工，不必等待整单委外全部回齐；若缺一个必要部件，其余部件数量再多也不能直接算成可生产套数。开工门禁仍需结合产品工序和配套用量确认。原材料领料按生产订单额度，员工工序报工按排产执行数量，两个口径分别校验。

## 5. 每日报工

### 5.1 录入方式

由车间负责人选择生产日期、车间和任务，批量录入多名员工、多道工序的产量。一个表格行表达“某位员工、某天、对该产品的某一道工序完成了多少”。

| 字段 | 来源或规则 |
| --- | --- |
| 生产日期 | 实际做工日期，与系统录入时间分开；允许补录的时间范围待定 |
| 车间及负责人 | 当前负责范围；后端也校验可操作的车间 |
| 排产单、任务单、订单 | 从车间任务带入，不手填关联 |
| 产品及图片 | 从排产产品带入 |
| 加工部件 | 工序加工对象为 BOM 部件时必填；整产品工序可不填 |
| 工序 | 仅选本任务所需、属于对应厂内工艺的工序 |
| 员工 | 实际完成工作的人，默认选择本车间有效员工；跨车间支援待定 |
| 报工单位 | 从工序带入，只读 |
| 实际完成数量 | 本行实际做过的数量，必须大于零 |
| 合格数量、不良数量 | 非负，二者之和等于实际完成数量；建议用于分开看产量和质量 |
| 标准工价 | 按产品＋工序带入，显示元/对应单位 |
| 计费数量 | 取值规则待 Q5 确认，不能默认不良品一定不计费 |
| 工费金额 | 计费数量 × 本次记录工价，金额按明确精度计算 |
| 备注、附件 | 异常说明及必要的现场图片；附件是否必需不预设 |
| 记录人、记录时间 | 系统记录，和实际生产员工、生产日期分别保存 |

工序数量允许的小数位根据单位配置；根、片等计数单位建议只允许整数。单价建议保留 4 位小数，金额按行四舍五入到分，再汇总行金额，避免报表与明细金额不同。

### 5.2 工价规则

已确认按产品＋工序带价。进一步建议：

- 按实际生产日期选择有效工价；同一产品工序不能同时存在覆盖同一天的两个有效价格。
- 报工保存记录工价版本、单价、计价单位，提交时校验价格版本。历史已确认报工保留当时工价，后续调价不能重算旧工费。
- 修改生产日期、产品或工序时重新校验对应价格，并提示变化。
- 缺少标准工价时明确提示先维护工价；可保存待完善草稿，不能当成零元自动形成有效工费。
- 普通报工页面建议不直接改标准工价；临时改价是否开放、由谁审批，单独确认，不默认负责人有改价权限。

### 5.3 保存与确认建议

建议只设置“草稿、已确认、已冲销”，本期不额外增加多级审批。负责人检查无误后确认，已确认记录进入正式产量和工费统计；是否需要其他人审核另行决定。

草稿可编辑。已确认报工纠错应留原因、前后值及操作人，通过冲销原记录并登记正确记录调整；不直接覆盖历史。若已发生下游交接或入库，必须先检查关联数量，不能只冲销工费而留下失真的库存。

同一员工同一天同一道工序可以有多条合法记录，不用日期＋员工＋工序直接禁止重复。应使用提交标识防止重复点击、网络重试造成同一笔重复入账；相似重复录入可提示核对。

## 6. 工序产量、产品产量与工费不能混算

### 6.1 工序数量换算

建议：工序计划工作量＝排产产品数量 × 每个产品所需的该工序加工数量。换算依据来自已确认产品工序清单，并保留本任务版本。

例：排产 100 套产品，每套有 2 根指定管件需要切管，则切管计划工作量为 200 根。张三做 120 根、李四做 80 根，切管合计 200 根；不能拿 200 根与订单 100 套直接比较。

如果这些管件还需打孔，打孔也是独立的 200 根工作量。切管 200 根＋打孔 200 根不能报成 400 套产品，更不能因此新增 400 套成品库存。

### 6.2 统计规则建议

- 同一任务、部件、工序的正常合格完成数，跨员工、日期、报工单累计，不得超过该工序计划工作量。
- 同一个物件完成不同工序，各工序可以分别计工费；物理产品产量不能按工序次数相加。
- 不同计量单位的产量不混加。可按工序分别展示根、片、套；金额在同币种下可汇总。
- 不良和返工可能让实际加工次数超过正常计划量，不能简单禁止所有超量，也不能放任正常报工超量。返工应标记来源、原因、数量及是否计费；规则确认前不开放普通报工绕过上限。
- 有明确前后关系的工序，后道合格产量需受可交接数量约束；金工与裁剪等平行分支不能强行排成一条直线。
- 多人共同完成一件工作时，需区分物理完成数量与工费分配。未定义集体计件规则前，不允许每人各报全量并重复增加工序合格数。
- 任务完工以必需工序和必要交接完成为依据；成品入库以仓库确认的实收为依据。装配报工确认不自动等同成品已入库。

### 6.3 工费示例

仅为计算示例，不代表真实标准工价：切管 0.20 元/根，张三计费数量 120 根、李四 80 根，工费分别 24 元、16 元，合计 40 元。打孔如另有工价，单独统计，不覆盖切管工费。

装配合格报工 90 套、仓库验收入库 80 套，应分别显示“装配合格 90 套、已入库 80 套、待交库 10 套”，不能把两项相加成 170 套。

## 7. 半成品交接与成品入库

委外回来的合格半成品可以成为厂内投入；“不做裁剪委外回来后再次委外车缝”仍保留，不应误解成禁止厂内工序之间交接。

厂内完工的半成品如何交给下一车间，正在确认 Q6：

| 实际方式 | 方案需要的记录 |
| --- | --- |
| 先入半成品仓再领用 | 完工交库申请、仓库实收、半成品入库、下个车间领料；库存标识包含任务产品、部件、已完成工艺 |
| 车间直接交接 | 交出车间、接收车间、来源工序、目标任务、部件、单位、交出量、实收量、交接双方、时间；转移车间持有量，不虚构仓库出入库 |
| 两种都有 | 每笔交接只走一种方式，同一数量不能既入库又直接移交 |

建议下一车间可用量只来自已确认接收；仅有前道员工报工不能当成已经收货。某工艺包含多道内部工序时，不必每道都生成仓库库存，按实际需交接的阶段形成记录。

最终装配/包装与现有成品入库衔接，保留生产任务、产品及来源完成记录。成品入库是否复用现有入口、由谁申请及验收需进一步核对。不能在员工报工和仓库入库两处重复增加库存。

## 11. 后续验收场景（尚未执行）

1. 已排产产品只进入实际选择的厂内工艺任务，外协工艺不混入厂内工序报工。
2. 同名产品不同标识不会带错工序或工价；车间负责人不能录入无权限车间。
3. 原料按原单位出库，半成品按套出库，报工按工序单位；缺换算时不能猜测可生产数量。
4. 领料申请不扣库存；确认发料只扣一次；库存不足、重复提交和并发请求不会超发。
5. 同一库存被内部领料和委外同时申请时，确认出库遵守共同可用余额。
6. 委外回货合格 390 套、不良 10 套，最多只能领其中可用的 390 套；生产可开多少还取决于其他部件是否配齐。
7. 排产 100 套、每套 2 根管件，切管计划为 200 根；两名员工累计合格超过 200 根时不能作为普通报工通过。
8. 切管、打孔各完成 200 根，两者不形成 400 套成品；不同单位统计不混加。
9. 同一员工同日同工序的两笔真实工作可分别记录；同一笔网络重试不重复入账。
10. 产品＋工序无有效工价时提示维护，不静默保存为零工费；工价单位不匹配时不能确认。
11. 调整新工价不改变旧报工；生产日期变化时重新核对工价版本。
12. 实际完成数不等于合格数加不良数时不能提交；工费按 Q5 最终口径计算。
13. 下一车间不能使用尚未确认接收的半成品；同一笔数量不能既直接交接又重复入库。
14. 装配报工 90 套、入库 80 套显示各自数量及待交库 10 套，不重复增加成品。
15. 纠正已确认报工保留原记录；下游已交接时不能无检查减少上游有效数量。
16. 工序、员工和工价停用后，历史报工仍能回溯来源、单位、单价和录入人。
17. 真实接口业务验证与 1920×1080 页面视觉验收分别留证；方案说明不替代测试结果。
18. 订单需要 500 米、已领 200 米、本次 120 米，确认后已领 320 米、还能领 180 米；草稿、待审核、退回不改变已领数量和实物库存。
19. 同一订单多产品、车间、领料人和单据共同占用材料额度，拆单或切换排产不重置余额。
20. 订单还能领 300 米、对应物料公共可用库存只有 80 米时，申请 120 米不能确认；库存充足但超过订单额度同样不能确认。
21. 两张待审核单各 200 米、剩余额度 300 米时，并发审核不能总共出库 400 米；失败单无部分扣账。
22. 同一采购行分三批入库，采购数量只统计一次；入库汇入公共库存，领料不要求选择采购或入库批次，审核页和流程不出现出库来源分配。
23. A 订单领取公共库存中的同种合格材料时允许通过，但必须受 A 剩余额度限制；扣公共库存、增加 A 已领量，不增加 B 自身已领量。已发委外必须减少同订单厂内剩余可领。
24. 库存“已领用”不误报实际消耗；审核确认记录完整的领料人、领料时间、审核人及审核时间。
25. 订单需求 500 米、厂内已领 200 米、委外已发 100 米时，还能领取 200 米；本次再领 120 米后剩余 80 米，委外回货不能把原材料剩余额度恢复为 180 米。
26. 领料分类与 BOM 原材料分区对应，不出现裁剪/裁片明细；面辅料大类不能混入裁片数据。
27. 委外半成品无已确认合格回库库存时不可领；不能拿 BOM 裁片计划量充当库存。已完成裁剪的真实合格回库半成品仍可按需求领取。
28. 切换管材、面料、半成品等分类后保留本单已选数量，跨分类同一需求不重复获得领料额度。
29. 基本信息不出现销售订单字段，产品候选仅来自所选生产订单；选择产品后展示对应 BOM 分类及半成品，切换产品不能重置订单材料额度。
