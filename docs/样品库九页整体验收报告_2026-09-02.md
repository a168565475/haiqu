# 样品库九页整体验收报告

## 验收范围

本次按 1920×1080 桌面端规格，完成并复核以下九个页面状态：

1. 样品库存列表
2. 样品出库列表
3. 样品借出列表
4. 样品入库批量选择弹窗
5. 样品出库批量选择弹窗
6. 样品借出批量选择弹窗
7. 样品入库单详情
8. 样品出库单详情
9. 样品借出单详情

## 页面与路由结果

- 左侧样品管理统一使用“样品库”入口，库存、出库、借出通过三个选项卡切换。
- 三个列表均读取真实分页接口；单据编号和“查看”进入对应只读详情。
- 三个操作按钮打开对应批量选择弹窗，提交后由系统生成编号、操作人和操作时间。
- 入库单详情可进入来源样品跟进单；出库和借出详情还可进入来源入库批次。
- 借出详情保持当前业务范围，不提供归还入口、预计归还日或归还状态。

## 数据与业务规则

- 库存默认展示剩余库存大于 0 的入库批次，也可筛选查看剩余库存等于 0 的批次。
- 入库支持分批、多次操作，累计入库不得超过打样数量，入库位置必填。
- 出库和借出从可用库存选择，并使用提交时可用库存进行并发变化校验。
- 邮寄出库要求快递公司和快递单号；业务员带走不保存快递字段；其他方式要求备注。
- 借出要求借用人和用途 / 备注，借出数量持续占用可用库存。
- 可用库存按“入库数量 − 已出库数量 − 借出数量”计算。

## 接口与权限

- 库存接口：`/api/v1/sample-inventory/`
- 出库接口：`/api/v1/sample-outbound/`
- 借出接口：`/api/v1/sample-loans/`
- 三类接口均包含列表、汇总、选项、可选数据、创建单据和详情查询能力。
- 查看权限分别使用库存、出库明细和借出明细的查看权限；创建操作使用对应单据新增权限。
- 真实接口覆盖 400 参数错误、403 无权限、404 单据不存在和 409 库存已变化 / 数量超限。
