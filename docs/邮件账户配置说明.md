# 账户级邮件账户配置

## 部署前置条件

1. 后端镜像需安装 `src/backend/requirements/base.txt` 中的 `cryptography`。
2. 在部署环境的 `.env` 设置 `EMAIL_ACCOUNT_FERNET_KEYS`。值为一个或多个 Fernet 密钥，以英文逗号分隔；第一个密钥用于加密新授权码，后续密钥只用于兼容轮换前的数据。
3. 创建数据库迁移后，按发布流程执行 `python manage.py migrate`。

可用以下命令生成密钥（不要把实际密钥提交到仓库）：

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## 使用方式

- 每位有效员工在“系统配置 / 邮件账户”维护自己的 SMTP 邮箱。
- 仅支持 SMTP 的 STARTTLS（通常为 587）和 SSL/TLS（通常为 465）。用户名填写完整邮箱或服务商要求的账号，密码填写授权码或应用专用密码。
- 报价发送会使用当前操作账户中“启用且默认”的邮件账户；没有此配置时会阻止发送，不会回退到旧的全局 `EMAIL_*` 环境变量。
- 测试发送仅在用户输入指定收件邮箱并确认后执行；测试收件人、授权码和密文不会写入审计快照。

## 密钥轮换

轮换时先将新密钥放在最前面，并保留旧密钥，例如：

```text
EMAIL_ACCOUNT_FERNET_KEYS=<新密钥>,<旧密钥>
```

确认所有账户已重新保存授权码后，再移除旧密钥。若密钥丢失，原授权码无法恢复，只能由账户所有者重新填写。
