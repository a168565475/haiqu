## 滚动条与错误提示配色

可见滚动条采用 `--erp-scrollbar-track` / `thumb` / `thumb-hover` / `thumb-active` 四个用途色，由三套色表分别提供蓝灰、暖灰褐、深蓝灰配色。禁止用文字色或边框色在业务页面另行覆盖。原生滚动条优先使用 `scrollbar-color`，WebKit伪元素作为兼容路径；已有明确WebKit尺寸的PDF/采购编辑容器保留 `scrollbar-color:auto`，避免标准属性优先级使原宽度失效，颜色仍取共享伪元素规则。隐藏、尺寸及overflow不由配色决定。

Element Plus的错误语义有两套名称：按钮等使用 `danger`，Alert使用 `error`。`_components.scss`将二者统一映射到主题 `danger` / `danger-soft`，不可遗漏后者而回退组件库默认浅粉底。错误信息和重试动作继续保留。

## 弹窗表单控件规范

2026-10-19 用户看过新增客户、编辑客户和 BOM 用料三个实页小样后，确认推广到所有业务弹窗。所有业务弹窗必须使用 `AppWindowDialog`，普通单行输入、选择器、日期、级联、自动完成和数字输入统一为：高度 `32px`、左右内边距 `10px`、圆角 `5px`、文字 `13px`，纯色 `--erp-color-surface` 底和单层 `1px` 内侧边缘，不使用渐变或浮起阴影。

弹窗作用域中的 `--erp-dialog-input-border`、`--erp-dialog-input-hover-border`、`--erp-dialog-input-focus-border` 分别引用主题的普通边框、强调边框和焦点色。输入文字、占位文字、只读和禁用状态仍使用对应的 `--erp-input-*` 语义色。页面筛选区继续使用原有 `32px` 高、`12px` 留白、`8px` 圆角与渐变材质，不随弹窗调整；按钮保持原样。业务窗口外壳采用 `AppWindowDialog` 的实心表面，业务组件不得重新覆盖为玻璃渐变或背景模糊。

状态和内部功能优先保留：校验失败的边缘（含悬停、聚焦）使用 `--erp-color-danger`；只读文本字段使用 `--erp-input-readonly-background`，日期/级联控件为实现选择而生成的 readonly input 不算只读字段。数字输入有加减按钮时保留组件的按钮避让内边距，无按钮时才用左右 `10px`；带字数统计的文本域底部保留 `22px`，避免覆盖正文。

原生文本/密码输入、原生选择器和文本域同样执行这套规则；文件上传、复选框、单选框等非文本控件不套用文本框样式。原生文本域保留业务计数器所需的底部留白。

现有 `ElMessageBox.prompt` 原因输入也复用同一套平面样式，包含其 `.invalid` 错误边缘；此项只统一输入外观，保留系统确认框的原有壳层、验证和确认/取消行为。

文本域沿用同一套平面表面、边缘、文字和禁用态，只保留业务所需的最小高度与可调整方向。弹窗局部样式不得重新引入渐变、浮起阴影或另一套普通输入尺寸。`.paper`、`.quotation-document`、`.a4-canvas`、`.contract-sheet` 纸面与打印区域保留专用布局。

2026-10-19 补充确认：弹窗 `.el-table` 内编辑控件也使用纯色底、5px 圆角、13px 字号及同一套状态边缘；只保留其原有高度、内边距、表格行高、列宽与数字按钮避让，不统一拉高到 32px。新增弹窗/抽屉必须先接入 `AppWindowDialog`（旧标签别名须明确导入该组件），不得依赖 Element Plus 全局注册的 `el-dialog` 或 `el-drawer`。`PopupComponentUsage.spec.ts` 检查这类绕过。系统确认提示继续使用既有 `ElMessageBox` 组件，表单窗口不以它替代。

新增主题时：

1. 提供完整色表，逐项对应现有用途；深色的color-scheme设为dark，分别定义文字、透明表面、遮罩和图标，不能只反转背景。
2. 在theme.scss注册对应主题及预览作用域，并将它加入完整性检查。按用户确认的范围在theme.ts的可用主题中启用。
3. 验证真实页面、浮层、禁用态、对比度、刷新后的主题保持；菜单动画和布局不用改。

组件示例：表头用var(--erp-table-header-background)，正文用var(--erp-table-text)，品牌按钮表面用var(--erp-button-primary-surface)，纯颜色位置仍用var(--erp-button-primary-background)。不要用“浅色/深色”判断散落在各组件里。
